# Blender / Godot 近岸样段实现与验证边界

## 运行链

游戏输入 → 原 120Hz 船模型 → 位置/朝向/划桨事件
→ GLB 艇壳 + 实时像素人物/桨纹理 → Godot 正交 3D 视口
→ 原 2D HUD 与交互目标

岸景与艇壳分别实例化真实 GLB。水面是独立 Godot 网格与动态 shader，含短反射、距岸浅水风格渐变和随航速变化的尾迹。保留原人物素材、体量和划桨时序；人物/桨在 256×256 透明视口实时绘制，再放到有深度测试的水平 Sprite3D 上，因此岸和树可以遮挡它。不是把完整 Blender 视频贴到游戏中。

## 坐标与镜头

- 游戏平面 XY、北向上保持不变
- 局部原点为游戏 `(6000,2850)`，40 游戏像素对应1个建模单位；单位不是实测米
- Blender X=(gameX−6000)/40，Y=−(gameY−2850)/40，Z=高度
- 导出后 Godot X/Z 对应游戏 X/Y，父节点 X 比例为 1/cos(30°)
- 正交相机从西侧倾斜30°看向水面，画面仍北向上；地面投影与原2D镜头逐点一致
- 模型高度产生正常的小幅视差。角色纹理平面高0.12，最大约2.42px；系缆端点使用船头0.08和实际系缆栓0.42高度投影

原镜头跟随、速度拉远、暂停/地图返回与触屏输入算法未改。已测多画幅与缩放的地面投影误差 <0.01px。HUD截图验证与投影数学测试分开记录。

## 物理与路线隔离

原 STEP=1/120、MAX_SPEED=285、转向速率1.5、推进脉冲70、划桨间隔0.46，以及滑行/刹停阻尼0.43/3.9均保留。

模型只新增可选 `route_goals`、`navigation_check`、`interaction_check`。默认目标仍为9点全湖路线，默认回调为空，原路线逐帧行为应与上一输入/相机版本一致。

近岸样段单独配置3个目标。蓝浮台可见尺寸与实体矩形差<0.5游戏像素。由于79px艇壳长于旧31px圆形净空，样段额外检查船头/船尾及浮台胶囊采样；候选朝向和候选位置都须合法，静止转向也不能穿岸。此附加接触规则只在样段启用。

系泊要求原有朝北、低速、取物完成、持续E 1.25秒，同时船头到浮台边缘<=7px，含约3px护舷和小接触容差。原出发点距甲板15px，直接按E不会成功。没有伪造上岸动画。

F 或 `--full-route` 直接进入原全湖场景，不是将样段碰撞回调偷偷叠加到原版。

## 真实与改编

湖岸的平面轮廓来自既有 `lake_geometry.gd`，与原2024校园示意图描边一致。蓝色教学浮台类别有公开报道依据。具体模块尺寸、连接位置、石面、步道、植物、建筑立面及短取物位置是玩法/美术改编。浅水距离贴图仅控制视觉，不是水深测量。

## 证据

- `test_blender_sample.gd`：GLB实例、108点地面投影、直行/转向碰撞、近而未接触的系泊负测、地图输入释放
- `capture_visual_checks.gd`：四画幅真实HUD截图；水面可见、岸下遮挡、岸上可见三组真实深度缓冲探针
- `capture_blender_replay.gd`：普通输入24秒原生录屏，逐帧审计位移/转角/目标进度，不给模型写入位置或通关状态
- 原 `test_large_world.gd`、`test_input_camera.gd`、`audit_large_world.gd`：保持原全湖玩法与交互契约
- 独立性能测试使用实时运行；视频生成的离线固定30fps不作为实时性能依据

手机只验证响应布局和输入合约，未测试手机实机性能。整湖精细美术、真正登岸及主线关卡整合不在本样段范围内。

## 细节修订与阴影边界

新增叶片是实际三角网格，不是透明 billboard。叶片扇簇朝上，`.blend` 以 Blender 原生压缩格式保存，仍可完整编辑/重建。只有样段的 3D SubViewport 禁用网格 LOD 阈值，避免自动简化造成大块十字形树影。平面地表/石面/低草关闭的是投影，不是显示或深度写入；仍接收树影并保持原遮挡与岸碰撞。阴影距离、bias、透明度调整只作用于该视口的光源。

水 shader 仍为不透明单 pass、单张距岸贴图采样；使用两次低频平滑值噪声与小弧波段，没有 SSR、屏幕复制、新反射相机或透明排序。蓝平台反光基于同一局部坐标矩形的美术近似。原物理、原角色/桨时间线、原全湖场景均与首版字节一致。

性能变化及同机位证据见外层 `verification/art-refinement-comparison.json`。平均帧率下降约10.1%，p95帧时增加约30.1%，不得称为零成本；一轮配对运行存在调度波动，不能据此推断手机性能。
