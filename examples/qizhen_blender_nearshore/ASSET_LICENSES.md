# Assets and source references

The new north-bank scenery, kayak mesh, painted material textures, local shore-style distance image, Blender reconstruction code and Godot water shader were created for this project. No third-party stock model/texture pack or external Blender add-on was used. These authored additions follow the containing repository's license; this file does not grant rights beyond that repository's terms.

The existing pixel paddler, paddle rig, swan atlas and font were copied unchanged from the approved input/camera large-world prototype. Exact hashes and baseline attribution are in `preview/docs/ASSET_PROVENANCE.json`.

Fusion Pixel font retains its bundled SIL Open Font License at `preview/assets/licenses/FUSION_PIXEL_FONT_OFL.txt`.

Public Zhejiang University aerial/campus/teaching-dock pages were used as references. Their photographic images are not included or claimed as authored assets. The blueprint is a game adaptation, not a measured survey or current access assurance.
