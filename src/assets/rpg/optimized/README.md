# Lossless runtime maps

Original PNG files remain the artwork and source-coordinate authority. This directory contains only reproducible lossless WebP derivatives and `manifest.json`, generated by `node scripts/build-lossless-runtime-maps.mjs` using `cwebp -lossless -exact`. Names encode the source path to avoid collisions. Never edit derivatives manually; regenerate after source changes. Remove a derivative only together with its manifest entry.

Production HTTP and standalone builds consume these derivatives through `scripts/lossless-runtime-assets.ts`. Development retains source PNG imports. The build checks source and derivative SHA-256 hashes to reject stale or damaged derivatives. RGBA equality is verified separately before accepting a generated batch. No resizing, palette reduction, alpha loss or lossy quality setting is allowed.
