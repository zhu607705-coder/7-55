# RPG Player Artwork

- `player_down_0.png` through `player_down_7.png`: front-facing continuous eight-phase walk cycle.
- `player_up_0.png` through `player_up_7.png`: back-facing continuous eight-phase walk cycle.
- `player_side_idle.png`: dedicated right-facing neutral stance with both feet close and arms relaxed; Phaser mirrors it for left-facing idle.
- `player_side_0.png` through `player_side_7.png`: right-facing ordinary eight-phase walk cycle; Phaser mirrors these for left movement. Only frames `0 / 4` use modest opposite-leg contacts; frames `2 / 6` are grounded passing positions with overlapping legs, and the remaining four frames keep a compact recovery stance. Knees stay low and shoes remain close to the ground.
- Every runtime frame is a transparent `96 x 128` PNG with at least two pixels of transparent head and foot safety padding. The doubled source resolution keeps the existing world-space size and collision footprint while avoiding the former `48 x 64` upscale blur.
- `source/student_walk_gpt_image_sheet.png` and `source/student_walk_transparent.png` remain the previous four-phase source references.
- `source/player_walk_24pose_transparent_v2.png` remains the unchanged down/up source. `source/player_side_walk_8frame_generated_v4.png` and `source/player_side_model_9pose_generated_v4.png` are the active regenerated side-view sources. Each selected pose is one complete character drawing; the older `source/player_side_transition_*_v3.png` and `source/player_side_passing_close_v1.png` experiments remain historical only.
- `scripts/build-rpg-player-frames.py` keys the generated magenta backgrounds, extracts only whole connected characters, normalizes each whole pose proportionally to the same `104px` silhouette height, and aligns the head anchor plus foot baseline. It never cuts, shifts, scales, or recombines separate torso and leg regions. Unchanged down/up PNG pixels are preserved byte-for-byte.
- `npm run verify:rpg-character-sprites` checks complete silhouettes, real alpha, head/foot padding, identical side-view height, locked head/upper-body overlap, modest contact poses, compact recovery poses, nearly joined opposite-leg passing poses, and the recovered up-frame mapping. `npm run verify:rpg-player` requires all 24 walk frames to have unique hashes, validates the dedicated side idle asset and generated sources, and rejects a return to waist-sliced construction.

Phaser owns frame switching, direction mirroring, movement speed, collision bodies, and animation timing.
`RpgPlayerAnimator` in `src/scenes/rpg/RpgPlayerTextures.ts` is the shared runtime owner for all RPG scenes. All directions use eight walk frames at about `9.1 FPS` and the same `880ms` stride duration. The regenerated side idle is selected only when velocity is zero; moving direction changes remain inside the walk sequence. Phaser mirrors the same complete right-facing artwork for left movement.
