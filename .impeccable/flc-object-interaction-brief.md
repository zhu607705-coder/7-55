# Future Learning Center — physical object interaction correction

Mode: Experience. Ordinary native-game extension to the existing pixel-art world; preserve geometry, player scale and controllers. No new brand/world or approved comp. Native Godot, so no HTML/CSS detector. Use native Godot Control guidance and project art bible.

User rejected the prior full-screen action strips and hotkey-forward interfaces and explicitly made this a standing design principle: most core operations must occur through visible scene objects, drag/rotate/reconnect gestures, actual levers/dials and recognizable joysticks. Screen buttons remain only for necessary navigation/secondary settings. Do not turn the picture of an object into a disguised action button: its location, grip motion, commit boundary and feedback must agree.

The four current workbenches share a uniformly scaled transparent worktable and independent generated controls. Solar uses a draggable panel hinge, part fitting, lamp and physical run/pause/return lever; robot uses removable/rotatable track modules, destination guide and trial lever; signal uses actual plug/cable dragging and pattern cards placed onto the editor, plus movable receivers; mechanical uses gears, belts, tension dial and trial lever. A physical rewind crank undoes assembly. A movable notebook provides voluntary page-by-page clues. The sole ordinary Button per scene is exit navigation.

Default play has no action row, numbered port buttons, visible hotkeys or persistent control tutorial. Scene goals/abnormal outcomes appear briefly in the bottom safe zone. Touch walking uses an analog joystick and tap-to-approach, with real pointer ownership, neutral release, focus cleanup and legal foot movement. Keyboard equivalents stay secondary and invisible by default.

Visual authority: user photos/floor art and prior physical props; source assets retain original bytes, alpha and provenance. The tabletop is a close-up of the active apparatus, with room context at the margins. Fine pixel scale, oblique orthographic axes, gray/blue metal and restrained details. Not a claim of strict 32-color quantization.
