# 一页未落定 · 7:55 独立可玩样例

**目标：把这一页留在桌上，再亲手收起。**
这是 Godot 4.7.1 / GL Compatibility 的机制原型。它不接正式菜单，不读写正式存档，不发放签到纸或章节证明。这是可玩场景样段，不是最终美术。文件夹使用分层牛皮纸面片，纸、窗外树冠与字体复用现有项目；桌面与收音机为局部原生绘制。

## 直接玩

用 **Godot 4.7.1** 打开本目录 `project.godot`，按 F5。源包自带纸图和字体，不需要 Node、主仓库或资源同步。

- **拖蓝色窗**：看旧记录。窗内纸不是另一张可拿出的实物。
- **抓住纸或纸影**：当前这张纸停住。沿可见飞行轨迹往回拖。
- **双手操作**：一手把纸留在左侧；另一手抓右侧封面向左翻开（也可轻点）。松开文件夹的手不会释放纸。
- **松开抓纸的手**：纸继续向前；文件夹保留刚才的改变。捕获来自实际空间接触，不是计时完成。
- **点落稳的纸**：亲手收起。落入夹层本身不会完成样例。

单指/鼠标可先布置文件夹再回溯纸。无精准抢点、失败次数限制或强制等待。纸飞走后，最后可见位置保留可抓的纸影。

`选项` 内才有暂停、重试纸张、重置全部、退出、减少动态、可选声音与键盘帮助。辅助时间预览仅存在于此处，不是主要玩法。重试纸张保留文件夹；重置全部恢复两层。取消触摸、旋转屏幕或切后台会暂停纸张并清理手势，不会自动完成。

## 三层状态

```text
过去的只读记录 ── 可移动观察窗 ── 只改变看见的位置
当前纸张       ── 抓住 / 回溯 / 松手 ── 真实接触 ── 落稳 ── 手动收取
当前环境       ── 翻开文件夹 ─────────── 保留布置，不随纸倒退
```

广播停顿用收音机灯与可选轻提示音同步表达。它不是操作门槛，也不会冻结世界。没有新增“静音控制一切”的规则。

## 手机边界

- 首选双手分别操作两个物件，而不是两枚虚拟按键。
- 触点在按下时锁定物件；另一指不能抢走、释放或重复激活同一物件。
- 不同物件可同时操作。取消一指只取消该指；切后台/旋转取消全部并保留布置。
- 纸命中面至少 **48×48 px**，文件夹至少 **44 px** 高。窄屏纸面仍至少约 **32×39 px**。
- 持纸时局部轨迹与单个方向提示避开手指；没有第二张实体纸或重复线框。
- 初始画面没有按钮排、方向键盘或主要时间条。键盘只作后备。

桌面/模拟触屏测试覆盖 320×568、390×844、844×390、1280×720。**已查看托管 GL 实录；尚未进行物理手机、浏览器手动体验或最终美术验收。**

## 测试与导出

```sh
# 默认用 PATH 中的 Godot；必须为 4.7.1
GODOT_BIN=/path/to/godot node tools/run.mjs --test

# 可选：导出独立 Web 包，不连接正式游戏
GODOT_BIN=/path/to/godot \
GODOT_WEB_TEMPLATE=/path/to/4.7.1/web_nothreads_release.zip \
node tools/run.mjs --web /path/to/output
```

测试使用临时项目/数据目录，并核验正式存档哨兵字节不变。报告写入 `build/test-report.json`。Web 输出需要 HTTP(S) 静态服务器，不应双击 HTML 作为浏览器验收。

新人 40–50 秒是**设计目标，尚未经过真人计时**；游戏不靠固定倒计时强制达成它。

正式接入边界与已知验证限制见 [docs/INTEGRATION_BOUNDARY.md](docs/INTEGRATION_BOUNDARY.md)。素材身份见 [assets/provenance.json](assets/provenance.json)。

## 实际画面演示录制

`tests/capture_paper_rewind.gd` 用普通触摸事件驱动 24 秒竖屏完整路径，并绘制两个触点标记。专用 GitHub Actions `Paper rewind portrait demonstration` 在托管 Xvfb/GL 环境运行 Godot Movie Maker，再生成 MP4 与校验元数据。画面标注自动演示而非物理手机测试。headless 排练只证明输入路径，不能当成已经录到视频。
