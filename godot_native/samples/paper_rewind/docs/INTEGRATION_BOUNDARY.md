# 集成边界与验收说明

## 当前事实

- 独立目录：`godot_native/samples/paper_rewind/`，自己的 `res://`、场景、模型和测试。
- 未修改正式 `main.gd`、ChapterFour controller、存档 schema、菜单或签到证明。
- 生产 Web 既有 `samples/*` 排除规则不变。
- 当前这张纸的局部物理回溯是样例新规则；蓝窗里的历史记录继续只读。不能把所有旧投影变成实物。
- 文件夹只属于当前环境。纸的时间预览、回放、失败和重试不会关闭它。
- 广播是独立展示时钟及同步声音反馈，没有状态门禁或奖励权限。

## 不应误接的入口

`godot_native/scripts/chapters/chapter4.gd` 的 `c4_catch_paper` 属于 **A1 开场 `opening_handoff`**，要求 `opening_paper_at_noticeboard`、A1 与浅色操作，并发放 `attendanceRecordPaper`，继而启动 `paper_pickup → c4_external_time`。

它**不是收尾入口**。把本样例直接替换到该动作会更改开场的纸张取得时机。当前没有这样接入，也没有新增普通存档字段。收尾的具体触发位置、所使用纸张的身份、已取得证明的保留语义确认后，才能设计正式 controller 会话适配。未来适配应由 controller 发会话并验证可重演输入；不能信任视图的完成布尔值或动画结束。

## 状态机

| 状态 | 进入条件 | 允许的结果 |
|---|---|---|
| intro | 新开/全部重置 | 碰纸或文件夹开始；观察窗不改变物理状态 |
| forward | 松开纸/明确继续 | 实际空间接触进入落入过程；飞出后 failed |
| paused | 抓纸、预览、取消/失焦 | 可以继续布置，不结算 |
| rewind | 辅助键盘回溯 | 仅纸倒退，不在逆行时捕获 |
| landed | 前向捕获后实际落稳 | 仍未完成；可以收取或继续实验 |
| solved | 对落稳纸明确收取 | 本地一次完成；纸图与命中面消失 |
| cancelled | 明确退出/卸载 | 不再接受后续动作，不写正式证明 |

触点所有权独立于以上状态。每个触点只操作按下时选中的物件；同物件第二触点被拒绝，不同物件允许并行。视图的前后遮挡与命中优先级一致：历史窗在物理纸上方时，触摸只移动只读窗。

## 验证边界

- 确定性模型：逆行、环境保留、真实接触、宽捕获范围、15/30/60/120/144 FPS、一帧大步长、失败、重试、重置、跳过、重复完成与手动收取。
- 普通输入：鼠标、键盘、模拟触屏、对象直接拖动、可见轨迹投影、纸影恢复、界面宽度与最小命中区、后台/方向切换、减少动态、静音及广播同步。
- 双手：两种松手顺序、分别取消、同物件抢占、不同物件同时操作、历史窗叠在纸上、旋转/失焦/重置/退出后的过期释放、取消收取、窄屏完整路径。
- 使用 #177 `ec6f125` 的相同 namespace helper 与 19 个正反例，给当前样例按独立 project ID 条件注册三套测试。缺失子项目资源与错误项目测试归属仍会失败。
- 本云环境已知图形/Chromium 套接字访问受限；没有重复被拒绝的显示路线。headless 输入与导出成功不等于实际画面、浏览器、屏幕阅读器、音量或物理手机验收。
- 40–50 秒新人体验、真实双手舒适度、画面最终艺术整合仍待真人/图形环境验证。
