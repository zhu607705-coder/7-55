## 打开

在 Godot **4.7.1** 中打开本目录 `project.godot`，按 F6/F5。
或在仓库根目录执行：

```sh
godot --path godot_native/samples/north_real_plan_preview
```

无需同步正式游戏资产，也不加载 State / WebContent 等剧情 autoload。
本目录的 `.gdignore` 将样例与父项目的资源扫描隔离；生产 Web 预设也已有
`samples/*` 排除规则。没有修改正式入口、已有 A1/A2/A3、存档或控制器。

- 选择建筑和楼层。只有一层载入候选图；上层清空旧图并显示未实现状态。
- 拖动或单指移动，滚轮或 `− / ＋` 缩放；`全图`重置视图。
- `资料`展示官方出处、局限和缺失几何；`返回图像`或 Esc 返回。
- Tab / Enter 操作控件。所有控件最小高度44像素。缩放始终等比，不旋转或镜像。
- 查看资料不会启动下载，也不自动打开外部网页。链接可选中复制。

## 什么是真实来源，什么仍是候选

`data/north_plan_registry.json` 登记官方通知与附件链接。北1/2是2022-12-22
发布的2023年考试参考资料；北3/4来自2025-12-13官方通知，图签为2022.03.20。
北1图签为2022.03.18；北2为裁边 CAD PNG，日期尚未核验。北2附件标签有楼名
笔误，历史核查依据正文和内部文件名确定身份。北3/4原始附件内部文件名尚待
重新核对，登记为 `null`，不把工作时的标准化文件名伪装成原名。

**这些是历史考试参考图，不是2026年现状竣工图。** 已取得的4/4/5/5张分层图
只说明资料覆盖范围，不证明每栋目前只有这些楼层，也不证明整层均有房间。
上层退台、屋面和局部翼楼必须逐层处理。不得从 WFS `build_floor=6` 推断每栋
都有六层完整占用空间；也不得把已有游戏的六个时间状态当作六层。

四张 PNG 是用户批准的独立美术候选。保留批准的透明修正版本全部文件字节。
外围 alpha 为0，保留铺地/庭院和建筑为255；全画布 RGB 与生成原版一致。
布局方向保持原始候选，不做旋转镜像；尚未与图纸做像素/测量配准，因此不画
未经核验的地理北箭头。门洞、器具形状、尺寸、比例和绘图辅助痕迹仍有已知
差异。候选不能产生碰撞、房间边界或楼梯连接。各栋差异见登记表 `artCaveat`。

本样例没有重新托管大学原始图纸或附件。仅记录公开来源链接。
晨札像素字体为仓库现有 Regular 的原样副本；许可证随附于 `assets/MORNING_NOTE_OFL.txt`。
