7:55 · 原生 Godot 迁移阶段版本

这是仍在核验与完善的阶段版本。剧情和解谜由原生控制器运行，游戏运行不依赖浏览器、React、Phaser、Three.js 或 Node。

一、你下载的是哪一种包？

【Windows 运行包】
解压整个 ZIP，双击 7-55-native-windows.exe。资源已内嵌，不需要安装 Godot。
程序未做代码签名。请自行按设备的安全策略决定是否运行；本说明不建议关闭安全防护。
Windows 可执行文件由官方 Godot 4.6.3 模板导出，但没有在 Windows 设备上实机运行验证。

【Linux 运行包】
解压整个 ZIP，保持 7-55-native.x86_64 与同名 .pck 在同一文件夹。
在支持 OpenGL 的桌面会话里运行 7-55-native.x86_64。
本轮实际执行、可视检查和自动测试的平台是云端 Linux。

【Godot 源码包】
包内已经包含原素材、转换后的视频和数据，不需要另找资源。
安装官方 Godot 4.6.3，导入包内 project.godot；首次等待资源导入完成，然后按 F5。
官方版本：https://godotengine.org/download/archive/4.6.3-stable/

只有直接下载 Git 仓库的开发者，才需要在仓库根目录额外执行：
node godot_native/tools/sync_source.mjs
bash godot_native/tools/convert_media.sh
后者需要 ffmpeg。普通源码 ZIP 和运行包无需执行这两步。

二、操作

手机：点击、滚动、拖动物品；部分解谜需要按住或按原提示输入。
地图：WASD 或方向键移动，空格交互；右键拖动视野，滚轮缩放。
皮划艇：交替 A / D 划桨，按住 S 再划桨可倒退。
触屏布局提供对应移动与交互控件。390×844 缩放与触摸事件测试不等于实体手机验收。
Ctrl+Shift+D 可打开测试检查点；测试会话不会覆盖正式自动存档。

三、已验证范围与剩余差异

已运行原生状态/存档/输入/媒体/碰撞/小游戏测试，并以真实控制器、已签发会话和小游戏输入轨迹连续验证第1章至第4章最终确认；途中在章节边界保存再读取。
连续测试会明确设置交互站位，不是人工从头走遍全部地图。截图检查与逻辑跑通分别记录。
浏览器原版预览被当前环境扩展拦截，尚未完成运行时逐像素对照。

仍待核验的行为差异包括：浙大钉的校园 Wi-Fi 准入与加载/拦截流程、微信攻击及体艺异常的部分时序/音效/中断后恢复，以及搅拌机选项随机排列。这些并不都属于装饰细节。
本轮已实际测试启真湖必需的 CC98、图书馆、微信、地图与天气入口，以及窄屏所需控件。

仍需完善的呈现包括：部分手机特效（如微信攻击、体艺异常效果）、部分地图设备近景/菜单弹层、图书馆入口设备与环境细节、部分第四章转场/能量效果/灯光融合。完整视觉等价尚未验收。
Windows、Android、iPhone 没有实体设备测试。不要将本阶段包理解为最终发布版或“完美移植”。

更多实现与检查范围见 README.md、docs/INDEPENDENT_PARITY_AUDIT.md 和各章节说明。

四、首次资源导入与内存

源码包包含原作的大尺寸素材。第一次导入请只开一个 Godot，先关掉其他大型构建/测试。
若内存不足导致导入被系统终止，可以临时在 project.godot 旁创建 override.cfg：
[editor]
import/use_multiple_threads=false

[threading]
worker_pool/max_threads=2

不要覆盖已有的 override.cfg。等全部素材导入完成后，移走这份临时配置，再启动游戏。
这只是编辑器资源导入的低内存选项；Windows/Linux 运行包已经导入资源，不需要这一步。
