# Campus UI Sans

A presentation-only, Simplified Chinese body-font subset derived from **Noto Sans
CJK SC Regular 2.004**, distributed under the **SIL Open Font License 1.1**. The
family/PostScript/CFF names are changed to Campus UI Sans / CampusUISans-Regular.
This is not an upstream Noto release and is not endorsed by Google or Adobe.

- Upstream: https://github.com/notofonts/noto-cjk
- Upstream font copyright: © 2014–2021 Adobe (http://www.adobe.com/).
- The local distribution's `fonts-noto-cjk/copyright` also records © 2010–2012
  Google Corporation. Both notices and the complete OFL are retained in `OFL.txt`.
- Original input: `NotoSansCJK-Regular.ttc`, collection face **2** (SC).
- Original SHA256: `b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`.
- The build host has the font and Debian-format copyright file, but **no installed
  dpkg record or changelog for fonts-noto-cjk**. Its Debian package version cannot
  be verified and is not guessed. The exact font version and SHA above are the
  reproducibility authority.

## Rebuild

Use Python with `fonttools==4.61.1` and an externally obtained original TTC that
matches the recorded SHA. The generator does not download fonts or inspect
personal font directories, saves, user documents, or test fixtures.

```sh
python3 godot_native/tools/build_campus_ui_font.py --source /path/to/NotoSansCJK-Regular.ttc
python3 godot_native/tools/build_campus_ui_font.py --source /path/to/NotoSansCJK-Regular.ttc --check
```

The `.otf` is an actual OpenType CFF font, not a renamed TTC. Its CFF and OpenType
family names are both changed. Upstream copyright/license metadata is retained.
The generator preserves original font timestamps, pins the tool version, sorts
inputs, and verifies regenerated bytes. `campus_ui_font_manifest.json` records
every input hash, coverage, missing characters and the output hash. Regenerate
after authored runtime text changes. A source-byte change can update this
manifest even when its glyph repertoire stays identical.

Sources: text files under `src`, `godot_native/scripts`, and
`godot_native/data/native`; extensions `.json`, `.gd`, `.ts`, `.tsx`, `.tscn`,
`.tres`. JSON strings are also decoded to include escaped authored characters.
The subset additionally requests Latin U+0020–024F, General Punctuation,
CJK Symbols/Punctuation and Halfwidth/Fullwidth Forms. Only characters present
in upstream can be retained. Printable ASCII and all current authored Chinese
characters are verified; this is **not** a full CJK font or a guarantee for
arbitrary player names/imported text.

Some UI symbols are absent from upstream. The manifest lists them; a consumer
must provide a suitable fallback or non-font icon. Fusion Pixel covers only some
of those symbols. No runtime font switch or UI script is part of this artifact.
All normal UI roles now use the same Campus family: body, titles, clocks,
numerals and buttons. Role names do not select a separate display family.
The bundled Fusion resource is retained only as an explicit missing-symbol
fallback, not as a source of normal Chinese/Latin/digit lettering.

Runtime integration uses `native_typography.gd`. Known phone UI symbols absent
from both bundled fonts are drawn by `native_symbol_icon.gd` as deterministic
pixel primitives while retaining the control's original text and input owner.
The font manifest remains a glyph-coverage report, not a report of those vector
fallbacks. Arbitrary external text can still contain unsupported characters.
