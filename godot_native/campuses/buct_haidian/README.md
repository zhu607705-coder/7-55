# 海淀校园：独立教学楼与荣茂馆

从默认入口选择“海淀校园漫游”。返回入口后可进入原朝阳校园或继续《7:55》。本场景不读写故事进度、主存档或备份。

## 已实现范围

原1448×1086海淀艺术地图内，一栋三体量连通的教学楼改为真实RGBA独立对象。楼体、窄接触影、脚碰撞、透明像素拾取与403个精确脚深分区随同一对象移动。隐藏后露出独立净底；复位恢复原登记位置。

荣茂图书馆现已使用独立真实RGBA楼体、有限路边净底和窄接触影；其余对象仍使用原图登记层。原67组包含校内主体、合并楼群和邻接背景；它们不代表67栋已完成透明拆层。北侧入口是文化展示示意点，未绘制不存在的门亭。

开放路线为北侧入口→教学楼→图书馆。只对沿途部分树冠/树脚建立遮挡和碰撞。访客使用共用真实四向北化学生资源，身高18源px，脚半径3源px，手动速度88、导览速度106源px/s；本轮馆楼不改变角色图、步态或运动参数。

## 操作

- WASD/方向键行走，点击或触摸开放铺装寻路
- E/附近地标：介绍；M/全图：浏览；R/回北侧入口：复位访客
- 建筑检查/F3：教学楼显隐H、移开T、复位B
- Esc依次关闭建筑检查、介绍、全图，再返回入口；也可点击“返回入口”
- 建筑按真实alpha拾取；透明矩形和地影不参与选择

## 原图与配准

所有生成PNG保留原字节。教学楼与影共用单一比例464/1614，原点(408,144)，完整PNG世界高度280.29739777。纹理、alpha拾取、脚深和碰撞共用同一变换。

三片净底各有明确world_rect：西[424,160,226,180]、东[754,250,106,162]、中[588,247,185,141]。各片按实际PNG大小做等比cover/crop；中段只在真实生成地面之间做14源px重叠过渡。技术mask限制使用范围，原蓝球场和保护树保留原像素。

隐藏净底是艺术推定：原占地外轮廓仍可辨，东侧保留两处小低草块。它不是测绘还原或真实可通行地理证据。建筑细节亦包含补绘推定。地图只用于文化展示。

## 渲染与资源

默认sprite_regions，各分区共享Texture2D和ShaderMaterial；保留polygon回退。403条是单栋的脚深分区，不是403栋楼或403次绘制。RGB使用mipmap缩小采样；alpha固定LOD0，避免轮廓扩张。body PNG的.import内mipmaps/generate=true是必需发布设置。

固定源景保护区与复位要求像素0差。完整PNG和分区RGB允许已量化的最多1/255 GPU插值舍入，并独立要求alpha覆盖不缺片。独立源工程同机llvmpipe、1280×800：旧版150draw/420nodes，三轮median8.621–8.726ms；新Sprite172draw/834nodes，median10.882ms/p9513.358ms。纹理内存50,745,989→88,955,750B；增加22draw、414nodes和38,209,761B纹理。此测量不证明全部校园或Web设备可以线性扩展。

## 测试

轻量静态检查：`node godot_native/tools/test_buct.mjs --source-only`

相关原生回归：`node godot_native/tools/test_buct.mjs`。Linux runner为每进程创建全新755-native-check-*目录，保护真实存档。运行前将TMPDIR/TEMP/TMP和全部XDG指向拥有权限的工作目录。测试包含原朝阳、海淀实际路线、输入、显隐碰撞、重复释放及入口/故事往返。

实际GPU证明使用`tests/verify_buct_haidian_render.gd`，需显式BUCT_HAIDIAN_PROOF_DIR输出目录和BUCT_HAIDIAN_REFERENCE_DIR已验源图目录，由单一图形任务串行运行。普通headless检查不证明画面正确。

本地相关测试：原朝阳源图284项、行走115项；海淀60项、516物理tick路线0越界；入口797项，包括存档、完整输入映射、窗口参数及重复释放。正式GPU已验证正常/隐藏图对已验独立源景0差、前后遮挡、复位及两手机尺寸实渲。正式手工也已通过两次海淀进入/返回、全图实际屋顶选择、H/T/B、朝阳往返和《7:55》开场；正常退出无错误。完整历史聚合仍待远端CI按精确head执行。未验收的其它楼体、失败候选、证据截图、旧delivery或缓存不在运行时闭包内。


## 荣茂馆增量（2026-10-12）

基于包含三校区入口和四向学生的 #126。馆PNG为1115×1411，原点(399,246)，等比196/1115，脚深、拾取、碰撞和显示使用同一登记。三个全纹理pass共享楼体和1D精确脚深纹理；只对当前角色和附近南树脚Y=462分区。此机制仅认证单列单脚线建筑，多庭院需另验表面归属，不能直接复用bottommost。

旧馆楼UV主体、旧碰撞、宽影和宽影补底成对退役。正常可见的南端141源像素使用真正生成的净底；13997源像素不可见核心仅保留原生近似铺装托底。馆为固定普通对象，支持真alpha选择、介绍、脚碰撞、前后遮挡；不开放整栋隐藏或搬移。原教学楼检查操作不变。

本轮本地headless72/72：原入口→教学→馆路线513物理tick，0越界；真实键鼠事件、两楼选择、状态不变与6次完整释放。固定1280×800 GPU A/B/A回切0差，馆外源像素0变化；原南树103像素、蓝球场和南步道对源图0差。墙后非法站点仅作为几何遮挡探针，未宣称可行走。紧凑组件此前另经236项及16组四向前后实际GL证明。

同机llvmpipe实测：172→174draw、853→855nodes；纹理172416666→189481398B，净增17064732B，超16MiB目标287516B。基线前/后median16.098/13.454ms、p9522.513/19.927ms；新馆median15.496ms、p9535.748ms。单轮有明显波动，不能据此声称加速或全校园可线性扩展。后续批量对象需可见范围加载、共享纹理及内存预算。
