# Mechatronics workbench review

The 2F electrical laboratory now has an assembly island: one 320-world-pixel
steel bench, two tool carts, two seats and a parts rack. It occupies the existing
room ground polygon. Doors, room masters, ground boundaries, stairs, elevator
arrivals and the shared player foot box are unchanged. The arrangement and
transmission experiment are game design, not a measured site equipment list.

## Play

Click the central bench to walk to it, or stand nearby and press Space. Install
a gear from the parts tray, fit a belt and press the tabletop switch. Observe
where the drive stops, then change the assembly and try again. The goal is to
move the feed block right to the white mark. The small gear leaves a visible
gap; the large one jams; a loose belt slips; an overtight belt stops the drive;
open and crossed belts turn the output in opposite directions. Feedback follows
the physical trial, without consuming parts or restarting the room.

- Pointer/touch: tap a gear or drag it onto the middle axle; tap the belt,
  tension knob and start switch. Tap the upper-right return control to leave.
- Keyboard: 1–3 select gears, B changes belt routing, T adjusts tension,
  Space starts a trial, R clears the assembly and Esc returns to the room.
- Leaving returns to the same feet position. Reopening retains the installed
  parts during this session. Focus loss cancels the trial; it cannot finish
  while hidden. Reloading resets the experiment.

The floor view and close view share one `workbench_model.gd` instance. The model
owns installation, trial timing and result; `workbench_view.gd` draws independent
moving gears, belt and feed block over an empty raster bench. The assembly state
also appears on the room-sized bench. There are no chapter intents, rewards,
inventory transactions, NPC tasks or production saves in this review. Those
require a later authored controller contract.

## Reproduce

Set `GODOT_BIN` to the project-pinned Godot 4.7.1 executable. Rebuild room data
with `tools/build_building.mjs`, then run the native sample:

```sh
node godot_native/samples/future_learning_center/run.mjs --resolution 1280x720
```

For captures and real engine-input checks, set `FLC_CAPTURE_DIR` to an absolute
output directory and `FLC_WORKSHOP_CHECK=1`. Add `FLC_INPUT_CHECK=1` for existing
floor movement regressions. `FLC_TOUCH=1` simulates coarse-pointer input; use
`--resolution 844x390` for landscape or `390x844` for the scaled portrait shell.
The logical scene remains 960×540 with a uniform transform.

Export the same scene as an independent Godot Web review:

```sh
GODOT_WEB_TEMPLATE=/path/to/4.7.1.stable/web_nothreads_release.zip \
  node godot_native/samples/future_learning_center/build_web.mjs /absolute/review/lab
```

Serve the review directory and open `lab/index.html`. The export uses the native
floor and workbench scripts, an isolated project with no autoloads, and a separate
user directory. It does not mount the retired hybrid runtime. The export receipt
records import, native startup and Web export separately from browser acceptance.

- Workbench-only spatial snapshot based on `6f1278a`: 1652 checks, zero failures.
  Its 2F/3F/4F object counts are 163/362/175; all architecture equals the base,
  and the complete 3F and 4F definitions equal the base. This snapshot excludes
  the simultaneous wall-storage edits by another task.
- Native model: 88 checks, zero failures, including all 36 assembly combinations,
  30/60/144 Hz timing, cancellation, reverse travel, slipping and repeat starts.
- Desktop 1280×720 and scaled 390×844 each passed 13 floor-input checks and
  11 workbench-input checks. Landscape 844×390 passed 11 workbench checks.
  These tests exercise actual Godot input; touch is simulated, not physical
  device acceptance. Room and workbench captures were visually inspected.
- Current shared working tree: seven selected native validation stages passed,
  including import, startup, all-script parsing and the two focused suites;
  532 unrelated stages were not run. Its room suite passed 1738 checks with
  the parallel wall-storage changes present.
- Standalone export: import, startup and Web export passed on
  `4.7.1.stable.official.a13da4feb` with the matching no-thread Web template.
  Local HTTP served the expected HTML, JS, WASM, PCK and review image bytes.
  Browser interaction has not been verified: local browser control is disabled
  in Work settings. Native and export success are not production release proof.
