# 场景物件优先的交互准则与当前实现

用户于 2026-10-29 明确要求将其作为长期设计准则：大部分交互禁止依赖按键或铺在画面上的操作按钮，应通过场景中可以操作的对象完成，具有清楚的操纵杆及合适的实物机关。根目录 `AGENTS.md` 已记录此约束，适用于既有场景的修订及后续所有玩法。

## 当前四种操作台

- **太阳能车**：抓住面板的铰链把手，上下拖动调角度；从零件盘把不同面积的面板或传动轮拖到车上；移动台灯改变照射方向。台边的实体操纵杆向前运行、回中位暂停、向后归位。完整 30 秒竞赛仍由同一规则模型计算距离。
- **机器人轨道**：拖零件盘内的直轨、转弯、单向模块到对应插槽；抓住模块把手转动，或整块拖到另一格交换。拨动送达站旁的导向杆选择返程出口，再用实体试跑杆运行、暂停及归位。货物和空车必须完成实际往返。
- **双屏改稿**：直接抓线缆插头接入插座，或拖出插座断开；把实物图案稿拖到编辑屏里，观察传播和两次不同修改。拖动接收屏可交换位置，端口身份随实物保持。台边试传杆可重发当前稿件，重复稿件不能充当第二次不同验证。
- **机电传动**：齿轮、皮带从零件盘拖入装配位置，扭转张紧旋钮，握住实体试转杆运行。屏幕中的键盘操作条和方形操作按钮均已撤掉。

四种操作台均使用同一指针所有权、失焦和撤回规则。装配预览只在合法松手时提交；松手落在无效位置、系统取消或另一根手指结束时，不能意外装入、试跑或完成。回卷手轮撤回装配；台边的笔记本按需阅读、翻页请求线索，并可拖开避免遮挡机关。默认画面只保留必要的退出导航。

## 行走与入口

轻触实际工作台会先走到合法站位，再进入实物近景。手机用单一模拟摇杆和轻触地面寻路；摇杆按实际位移控制方向和速度，释放、取消、失焦、切层或进入操作台时归零。桌面保持键盘等价路径，但默认场景不展示热键说明或触摸方向按钮。

## 复现

```sh
GODOT_BIN=/path/to/Godot-4.7.1 node godot_native/samples/future_learning_center/run.mjs --motion-test --headless
GODOT_BIN=/path/to/Godot-4.7.1 node godot_native/samples/future_learning_center/run.mjs --signal-test --headless
FLC_CAPTURE_DIR=/absolute/desktop GODOT_BIN=/path/to/Godot-4.7.1 node godot_native/samples/future_learning_center/run.mjs --object-input-test --resolution 1280x720
FLC_CAPTURE_DIR=/absolute/touch FLC_TOUCH=1 GODOT_BIN=/path/to/Godot-4.7.1 node godot_native/samples/future_learning_center/run.mjs --object-input-test --resolution 844x390
```

普通窗口验收完全通过鼠标或触屏事件执行，无键盘事件；太阳能试跑按正常实时速度完成。机器人失焦时暂停，验收在记录到真实失焦后恢复窗口并实际推杆继续，不能通过改写模型位置或完成事实恢复。

引擎及 Web 模板固定 4.7.1。新工作台和实体控件是透明生成素材，原始文件在 `assets/puzzles/sources/` 保留；运行文件只新增 PNG 文本元数据，像素未改。提示、图案、轨道、传动和运动仍由实时独立对象组成，未烘焙进底图。

验证的精确源码、画面、输入结果及浏览器范围见 `OBJECT_INTERACTION_VERIFICATION_20261029.json`。四种台面仍是独立原生试玩：全楼 25 个房间的设计准则已统一，其他房间的具体谜题实现与正式存档接入不由本轮验收推定。Argon 外部审阅入口仍待明确。
