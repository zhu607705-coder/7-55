# 2F formula：数值白模，2026-10-30

来源：先在独立 Python 数值白模验证，现迁入 2F formula_model.gd；不修改 3F 工作树。
这是无量纲教学模型，不是实际太阳能赛车或电机标定。下文距离、质量、功率和能量均为模型单位；时间为模拟秒。输出不能写成实际米数、瓦数或赛车续航。

## 计划原参数

- 车体质量 0.8；compact 面积 1、质量 0.4；wide 面积 1.65、质量 1.1。
- 倾角 β∈{0°,30°,60°}；减速比 G∈{1,1.6,2.4}。G 越大，轮上力越大、空载轮速越低。
- 30 模拟秒，固定 dt=0.05；每情境穷举 18 配置，共36。
- sunny：α=30°；I 在 [0,10)、[10,16)、[16,30] 分别为1、0.2、1。
- side_light：α=60°；I 在 [0,10)、[10,18)、[18,30] 分别为0.8、0.15、0.8。
- 基准车：sunny=compact/0°/2.4；side_light=compact/30°/1.6。
- 同一场两车从 x=v=0 出发，用完全相同的 t、I(t)、α 和终止时刻。两车不互相碰撞，回环只改变显示位置，不把显示取模后的距离当里程。
- 计划未给价格或预算数值。这里把18种配置视为同一可用零件集合，不暗造货币成本或解锁门槛。

## 明确新增的教学参数

P0=12：每单位面板面积的参考光电输出功率；η=0.65：输出到机械功率预算的效率；ω0=80：电机空载角速度；r=0.1：轮半径；g=9.81：模型重力尺度；μ=0.18：滚阻系数；空气/机构二次阻力系数 c(A)=0.05+0.1A。
这些是新引入的玩具模型参数，不来自实车实验，也不宣称由计划原文给定。

## 方程

M = 0.8 + m_panel + m_payload（payload仅用于本次对照，不自动加入游戏要求）
P_e = P0·A·I(t)·max(0,cos(β−α))
P_budget = η·P_e
ω = G·v/r
τ_stall = 4·P_budget/ω0
τ(ω) = τ_stall·max(0,1−ω/ω0)
F_drive = G·τ/r
F_resist = μMg + c(A)v²
M·dv/dt = F_drive − F_resist，v≥0
 dx/dt = v

停着且 F_drive≤μMg 时保持静止；无反向运动、无蓄电池或再生制动。恒定ω0而随照度缩放stall torque，是有功率上界的教学近似，不是完整光伏I–V曲线或实际DC电机电路。

令 u=ω/ω0，则 0≤u≤1 时 P_motor=τω=4P_budget·u(1−u)≤P_budget≤P_e；u>1 时电机扭矩为0。传动不凭空放大功率。

## 积分与能量检查

使用隐式中点积分，v_mid=(v_n+v_next)/2；用二分42次求
v_next−v_n = dt·[F_drive(v_mid)−F_resist(v_mid)]/M。
位移Δx=v_mid·dt。于是离散式满足：
Δ(½Mv²)+F_resist(v_mid)Δx=P_motor(v_mid)dt。

若本步将停下，求实际移动时间 dt_move=Mv_n/[F_resist(v_n/2)−F_drive(v_n/2)]，剩余时间静止；不把负速度直接当里程。每步断言能量残差<1e−8、机械功率不超过预算。静止也可有光电输入，该部分没有转为机械功。

实现固定dt；游戏帧应使用累加器推进固定tick。若未来允许任意dt，须在光照片段边界拆步，而不是跳过暗段。

## 枚举与对照结果

| 情境 | 基准距离 | 最佳配置 | 最佳距离 | 胜过基准配置数 |
|---|---:|---|---:|---:|
| sunny |52.350065|wide/30°/1.6|62.517072|11/18|
| side_light |39.793756|wide/60°/1.6|48.374895|7/18|

真实权衡，不靠配置标签判赢：
- compact/30° 晴天无载：G1=48.617039、G1.6=59.723286、G2.4=56.009694。高减速比有起步力，但牺牲速度。
- 相同车加0.6负载：G1.6=44.731346、G2.4=47.132405，优胜关系反转。
- compact/60° 侧光无载：G1.6=45.835、G2.4=46.003，暗段较长时高减速比能更快重新起步。
- 最佳倾角随光源由晴天30°转为侧光60°；不是固定“30°最好”。
- 保持compact面积1，只把面板质量从0.4增到1.1，晴天30°/1.6距离从59.723286降到42.208583。
- 保持wide面积1.65，只把面板质量从0.4增到1.1，同条件从74.538401降到62.517072。质量成本确实进入方程。

## 必须保留的边界

给定计划里的两块板，wide面积/整车质量≈0.868，compact≈0.833。因此在本模型所测同倾角同齿比下wide弱占优（停驶情况相等）；不能宣称当前参数已证明“小板因轻而更快”。未为了制造反转暗加wide惩罚。

不过“大板自动赢”也不成立：sunny wide/0°/1.0仅43.0945，小于compact基准52.3501；动力、倾角和传动仍必须配合。若游戏设计要求两块板在某些同配置场景各有优势，需要另行明示预算/几何遮挡/结构阻力等真实约束，并重新验证，不以隐藏扣分实现。

## 验证

150项外层断言通过：两场可胜基准、108项步长对照、36项整场功率/能量约束、两项质量消融、全黑不动、重复运行一致。另每个数值步均检查能量等式及功率上界。

对dt=0.01参考解，36配置中最大距离误差：
- dt0.1：sunny 0.000810328，side_light 0.000731261。
- dt0.05：sunny 0.000196454，side_light 0.000177472。
- dt0.025：sunny 0.000043001，side_light 0.000038887。

此结果证明数值白模的可玩解和边界，不证明手机性能、视觉质量或真实车辆效果。
