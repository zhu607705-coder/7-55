# Schedule web-generated object sprites

These PNGs were generated through the signed-in ChatGPT **web page**, not by SVG,
procedural drawing, or a direct image-generation API. Original download bytes are
retained. The private generation-session link is retained only in the local task
handoff, not published in this repository.
Generation date: 2026-10-31. Model/version was not exposed by the page.

Purpose: replace Schedule's schematic tool/artifact pictures while retaining the
same draggable tasks, tool ownership, production dependencies and save authority.
No project files or personal images were uploaded. Prompts describe original
campus props, with muted metal/wood/paper colors, fine pixel clusters, upper-left
light, independent transparency, and no baked words or brands.

The view draws a source region around each visible object and uniformly fits it
to the existing interaction footprint. It never stretches or redraws the artwork.
The same source depicts a tool in its tray, while held, and on its assigned task;
the same artifact source depicts its task and its completed output. A/B and camera
numbers remain engine text, not rasterized/generated labels.

Limits: true transparent exteriors are verified, but generated antialiasing has
intermediate alpha (most camera interior is253/254), and colors exceed the strict
32-color art-bible palette. Some object edges have slight perspective. This is a
first integrated object set, not approval of every room's art or full palette
compliance. Actual small-screen silhouette and object/action matching are the
acceptance priority; do not claim a palette filter was performed.
