# Signal and portable-board raster objects

Thirteen independent PNG originals generated on the image-generation webpage on2026-10-31. Original bytes are preserved. Runtime source crops and uniform scales register objects; no SVG or procedural physical-object art substitutes for these originals. The private authoring session stays outside this repository.

`manifest.json` records source hashes, crop regions and source-pixel pivots. Monitor pivots register the transparent screen aperture; the sockets are separate objects at exact model port centers. Plug contact pivots point their bodies toward the preceding cable segment.

The cable renderer crops original strip pixels at runtime, then tiles that texture along the unchanged model polyline at8 logical pixels diameter (model radius4). Its generated highlights are not a solid-color line substitute. Model cable length truncates the path and places the plug at that actual endpoint. Runtime pulses, printed symbols, target indicators and failure marks remain functional overlays.

Flex has one board subtree. It includes the same deck, six ports, pillar, adapter, clips and cable nodes at either station. Station0 uses zero translation; station1 uses(+30,+14). Rendered points and input transforms share that translation. Station transfer never clones or rewires the model; role interpretation and proof are model-owned.
