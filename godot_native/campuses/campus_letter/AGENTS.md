# 校园来信三维样段：用户明确要求（2026-11-07）

- 第一人称负责实际操作和玩法，以正常人的眼高、尺度及操作距离构图。
- 第三人称只作可切换的场景总览，不以远距离模型台视角代替实际游玩。
- 采用精细、非像素的三维建模。对象有独立几何、材质和交互范围；优先复用合适的已有资产，并核对其近距离质量。粗糙方块、失真比例、破面及无细节材料不能作为完成版本。
- 物品表面及其上方不叠加说明文字。说明与状态放在玩家查看物件时的界面中。
- 与既有正式主线的进度、存档和发布入口保持隔离；本要求不自动改变其他已批准的主线美术。
- 本轮默认画面暂不显示玩法说明、底部解说或悬停说明；只保留必要导航。用户随后在实际浏览器中明确要求移除当前黑衣人物，因此本批样段不再渲染此人物模型及其坐姿/总览复用；对应操作必须落在可见物件，不能留下隐形人物交互。
- 模型细化与材质渲染须主动查找并核对真实网络参考，记录参考页及素材许可。曲面、倒角和近景结构增加有效面数；材质使用合适的颜色、法线与粗糙度，不用整体纯色替代。
