# Room302 native lamp and curtain studio

This bounded port reconstructs the previously reviewed two-stage studio against
`godot-version` base `0659d72fb6bd68eda22a2cac7afb4b384479c1a3`.
The lost final upload payload was not recovered byte-for-byte. This is a new
source reconstruction, validated independently against the current repository.

## Scope

- Exchange the three supplied lamp shades, then move and rotate the curtain
- Operate visible native objects; retain keyboard equivalents and explicit touch mode
- Keep the original 301 film prerequisite and original media-alignment completion fact
- Save accepted partial progress in an optional bounded `native.c4_media_studio` checkpoint
- Restore old absent-checkpoint and already-completed saves without inventing progress
- Use three byte-identical supplied PNGs from the original Room302 verification archive

Whole-room objectization, room geometry, portrait relocation and other new games
are excluded. Shared device sessions, original JSON, world geometry, and original
web runtime are unchanged. The six studio runtime scripts are self-contained;
they do not require the unpublished Room301 objectization stack.

## Input and authority

One pointer kind/device/index owns each gesture. Unrelated releases cannot finish
it. Cancellation, focus loss, resize, mode change, hiding and disposal retire the
gesture without committing an operation. The focused Return button retains native
Enter/Space activation. Main is the sole keyboard router while the studio is open.

The controller checks Chapter4 phase/floor/light, native chapter/mode/scene/context,
original film and legal checkpoint. Completion requires correct shade order,
curtain registration, and the original final controller answer. The UI writes no
fact, wallet, inventory or save directly. Stale modal event/submit/close callbacks
cannot affect replacement surfaces.

The studio temporarily hides the existing shell, retains its world viewport and
camera, and restores shell visibility, inventory state, input and focus on return.
Actual input family, not viewport width, selects touch affordances.

## Validation status

The rebuilt source passed Godot 4.6.3 asset import/editor parse and all 16
focused scripts with exit 0 and no script errors. Coverage includes 238 studio,
23 pointer/lifecycle, 279 authority/save and 80 actual Main-host assertions;
shared Chapter4 devices/context/world, ordinary save/domain/integration, and the
merged fishing presentation regressions also pass. The final continuous native
campaign completed chapters 1–4 with 823 checks and zero failures. Its existing
anchor-size warning remains a warning, not a script error.

Independent read-only review found and resolved stale retired-panel close signals;
the regression now proves old event, submit and close callbacks are inert.
Historical failed test runs remain in the recovery archive: a test-only unqualified
notification constant, an unsettled pre-entry focus fixture, and persistence
harnesses launched outside their required isolated /tmp location were corrected.
All 16 scripts then passed in a clean final run with isolated temporary save paths.
The full native aggregate and Web CI remain remote PR gates; this focused run is
not presented as an exhaustive local suite.

This reconstruction has not been physically tested on a phone or Windows, and
headless input tests do not constitute a fresh manual playthrough or visual/audio
certification. Original screenshots describe the earlier archived presentation.
