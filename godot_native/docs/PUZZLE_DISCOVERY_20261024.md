# 7:55：把规则变成玩家发现的东西

用户于2026-10-24明确将这一要求推广到全游戏，尤其是北教每一关。原来的“展扇、远近、借光”手记虽有旧册外观，但直接解释了变量与结果，仍然是答案说明页。新的要求涉及关卡结构，不能仅靠改标题、换纸张或隐藏按钮完成。

## 每关的检查标准

每关先写清五件事：玩家能看到的矛盾、能提出的两种解释、可以区分解释的实验、能推翻错误解释的反例、需要运用发现的新情境。步骤数量按这些推理转折计算，不按按钮数量或物件数量计算。主要推理仍遵守现有多来源证据要求。

基础操作要能被理解：哪里能拖、怎样试演、如何撤回、怎么离开，不应成为猜谜。规律、组合关系和答案则由场景证据承载。纸册可以缺页、套印、折叠、交叉索引；小谜题必须帮助理解当前机制，不能变成无关的开锁题。

试错给出可比较的变化：同一机关为什么失败、哪些现象共同变化、哪些仍不变。不给每个答案选项逐一判绿，也不自动固定正确子项让玩家靠枚举完成。能同时满足多项约束才交付结果；自然存在的物理锁扣与已知答案的自动判定要分开。

不以时间惩罚、试错配额、不可见热区、阅读勾选或极窄容差制造难度。允许玩家从场景独立悟出规则，也允许合法的不同解法。程序能证明输入与几何是否满足条件，不能证明玩家心里是否进行了推理；“防乱点”验收指反复点按、翻页、逐项枚举不能替代必要的物理关系和完整验证。

任何成为剧情门槛的新证据都必须进入原控制器、存档验证与迁移。可选册页、临时影拓与动画不拥有剧情进度。

## 梁祝：已接入的第一个样本

包装为《蝶影残谱》。未读懂时只见缺笔、成对的印框、局部图案与短批注；舞台幕名用“缺翼、重影、同灯”，不先报出操作规则。原有明确的键鼠/触控操作说明保留。

1. 先点台灯得到一次实际影拓。
2. 只改变一个因素，再点灯，取得可比较的另一张影拓。两张完全相同的影、多项同时改变的影，都不能说明某个因素的作用。
3. 符合本卷关系的成对影拓出现于残谱。拖动薄纸，使三个套印记号衔接，才读到该卷的完整图解。箭头键可移动纸片，空格覆印。
4. 回舞台用规律满足原有位置、尺寸、开合、遮挡和共用光源的组合条件。册页本身不摆正机关，不替玩家过关。

扇骨卷需要一对只改变开合的影；门前卷需要一对只改变道具远近的影；同灯卷分别比较灯的横移和纵深，避免只看见一种变化就得到全部规则。成对影拓来自实际接受的试演，不从移动过程、翻页次数或预置示例冒充获得。现场仍可独立推断，读懂残谱不是新剧情门槛。

实现位于 `theater_rehearsal_study.gd`、`theater_rehearsal_tracing.gd`、`theater_rehearsal_notebook.gd` 与排练视图；原排练模型和一次性会话验证保留。完整图解本身不含答案坐标。

## 北教逐关改造账本

本表是逐关设计与问题清单，不表示这些关卡已经全部重做。核查来源包括本地活动工作区的 `chapter4.gd`、`chapter4_clock_chain.gd`、`chapter4_clock_panel.gd`、201/302物件，以及共享源 `ChapterFourInsertedPuzzleModel.ts`、`ChapterFourInsertedPuzzleGame.tsx` 和原生设备导出数据。校时七步、201压台、302扫描台等本地修改尚不等于PR166中的基线，实施时必须分别核对，不能用旧分支覆盖。

| --- | --- | --- | --- |
| 大厅首次校时 | 钟壳刻印、事件残票、终端脉冲三者互证；先识别现场信号与缓存，再从起点和时长推时刻 | 拨轴比较响应，修复传动，核对两针与多路脉冲，换采样间隔排除冻结信号 | 七个阶段中仍有逐项试选和正确轴自动锁定；不能称作七步独立推理 |
| 傍晚再次校时 | 沿用符号字典，换一组事件票和不同漂移，使上一轮结果成为可排除的旧记录 | 用已学方法推新时刻；原数值及旧校正量在新脉冲下产生可见矛盾 | 避免照抄首轮点击顺序；依据必须先于判定可读 |

| 电梯历史 | 层站旧划痕、门灯、乘客残影分别提供楼层与时间关系 | 先预测停站，再调回放；完整六秒客流与门周期交叉验证 | 避免一段文字直接公布完整时序；校准与乘坐仍走原门槛 |

| 301档案索引 | 胶片齿孔年份残字、取景楼层剖面、画面用途各提供一个维度 | 根据三个独立证据筛抽屉；取出的片还要能与302三个地标一致 | 当前提示直接给年代、A3、入口导视，等同读答案；需改成可推断的图面 |
| 302影像对齐 | 破损胶片套、错位地标、遮挡处的局部轮廓 | 先判断旋转还是平移，再以入口、楼梯、荣誉墙同时校验；只合一处是反例 | 共享源及旧观察条目直接写“右移2、上移1、90°”；须由实际套片图替代，不能只删文字造成无解 |
| 201定位压台 | 试压纸、触点压痕和压头侧面共同说明平移与压力 | 单次试压比较位置、完整度和深浅；三个触点同时吻合且压力合适才完成 | 共享源仍直接给“−2、+1、3档”；本地物件版需逐项复核提示泄露与试压反馈 |
| 203线路恢复 | 接线端磨损、同色线束、不同楼层的断电响应 | 接一段并试电，排除短接；建立闭合关系后在另一用电组合下验证 | 不能在观察文字中先画出完整五边环；已存在的运输/线路多阶段需保留 |
| 202疏散路线 | 鞋底纹、方向、转角磨损及缺失箭头组成路径证据 | 先拼一条可达路线，再处理受阻或返程情境；局部连通不等于终点正确 | 当前本地已有往返设计，需验证反向运用，不退回四个下拉框 |
| 楼梯A：折返楼梯间 | 栏杆断纹和远处踏步在某视点相合 | 先发现投影连接，再真正走过；仅画面对齐不能凭动画造路 | 保留原图连接与步行验证；入口说明不能点名正确视角 |
| 楼梯B：环形错层楼梯井 | 同一栏纹在环形结构中反复出现，遮挡提供反例 | 视角相合还需切线和遮挡成立；换层后再用该规律 | 不能用路径亮线提前标完路线，保持原解与重复限制 |
| 楼梯C：双向换乘回廊 | 正反方向的连接纹、可动接缝 | 从先前视点得到的解在反方向不再通，必须重新组织换乘 | 不以连续点三个相机键代替路径推理；以实际通路裁决 |
| 楼梯D：三重折叠天井 | 三组空间痕迹共享部分参照，局部可对齐但互相牵制 | 建立多个约束，走完后通过实体门完成交接 | 保留现有四关源数据与主线门槛，不能新增自动过关视角 |
| A3参照／A2残影／204复原 | 参照房间、原地压痕和家具结构提供互补信息 | 桌、椅、讲台组合既要局部吻合，也要保持整室关系 | 不能把槽位直接标成与家具同名的答案；三项仍是原有无序完成集合 |
| 维修诊断 | 异响先后、油圈、回弹位置形成因果证据 | 分别试推、拨轮，排除看似合理但不解释全部现象的原因 | 保留材料消耗与正确维修事务；不增加随机故障或耗损惩罚 |
| 五区配电 | 配电板连线、负载变化、疏散路线分别约束拓扑与目标 | 按一区观察连带变化；必要通路亮而旁路不过载，才整体锁定 | 展示电路变化而非整套按键序列；单区变亮不能积累成过关 |
| 楼梯追逐与最后一分钟 | 之前学到的路面、空间和时间关系在追逐中再次出现 | 熟悉关系在压力下运用；失败只回本段安全点 | 此处是操作与迁移测试，不能突然插入未教的新密码或阅读题 |
| 返回旧钟／签到／灯与离场 | 前面恢复的时间与地点事实闭合，人物主题回收 | 用获得的结果完成原终局动作与交接 | 叙事收束不额外塞一套无关解谜；不替代既有灯资产与演出 |

## 验收与迭代顺序

先处理直接泄露答案与可枚举的核心门槛，再改造缺少反例/迁移的关卡，最后统一美术与翻页反馈。每关必须走一遍正确解、至少一种合理错解，以及不调整机制的重复点击/翻页输入。失败原因要能从当时已经可见的证据解释。需要变化的正式答案或存档字段，先更新共同数据/控制器与迁移验收；未完成这些，不宣布该关改造完成。

当前已落地的是梁祝残谱样本与全游戏规则约束。北教表内各关是审核过来源的重构设计，尚未据此整体替换。下批先完成大厅校时与301→302→201线，再依正式流程覆盖其余关卡。原生、浏览器、实体手机与自然全流程验收分别记录。
