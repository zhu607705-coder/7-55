# 校园分层地图整合

本次把已保存的校园 v12 分层源接入 `main` 的 Godot 正式运行路径，整合基线为 `a31f0862127b6a14d988c521537d32633a85f079`。仅更新 `campus_bootstrap`，不替换求是湖侧视地图、室内场景、剧情控制器或存档结构。提交候选不代表正式站已经发布。

## 运行与来源

- `art/campus_layered/active_selection.json` 和 `authoring.json` 是素材选择、坐标及导航支持的作者源。目录只保留实际编译输入，不包含历史候选、审核截图或试玩站托管文件。
- `tools/build_campus_layered_map.py` 校验作者源哈希，生成 `data/native/campus_layered_map.json` 及 `assets/native/campus_layered/`。当前为 569 个注册图层、633 个物件切片和 17 组三帧水面切片，共 684 张运行 PNG。每张纹理不超过 1024 像素。
- 当前 manifest SHA-256 为 `414127c2e6a9af9db59df9cc037c78b818562ac75a61ba0c0928a763e62e8c46`。重编译须保持该身份，不能用整张预览截图替代作者源。
- `scripts/presentation/campus_layered_map.gd` 负责草地、水面、地面、道路及抬高建筑/树冠。`world.gd` 只在校园使用它；不会把旧烘焙底图当作回退。缺失资源时拒绝通行，离开校园时释放纹理。
- 校园纹理归入 Web Chapter 2 内容包，不加入开场手机资源。现有图书馆物件、动画、NPC 反馈、手机分包及其他主线资源保持原有行为。

## 碰撞和输入边界

校园脚框为 16 × 10 世界像素，中心为角色锚点加 `(0, 36.5625)`；碰撞、地面点击、路标和路径规划使用同一场景参数。角色绘制及遮挡深度仍以 `anchor.y + 31.6875` 为准。其他场景默认脚框保持 19.5 × 14.625，中心偏移保持 `(0, 31.6875)`；图书馆新增的 320 节点/8192 边预算与角色绘制比例继续保留。

支持掩码只补充逐处复核的承重区域，不全局开放地面。实体、水面、原有剧情门槛和门扇碰撞仍然优先。成悦外侧道路修正增加 6,872 个支持像素，不删除原支持像素，也不改图像或建筑根部。

## 复现和验证

使用仓库固定的 Godot 4.7.1 与同版 Web 模板，安装根目录锁定的 Node 依赖，以及 Python 的 Pillow、NumPy。按原生 README 先执行源同步和媒体准备，再运行：

```sh
python3 godot_native/tools/build_campus_layered_map.py
GODOT_BIN=/absolute/path/to/Godot_4.7.1 node godot_native/tools/validate_native.mjs --profile full
npm run validate:release
```

校园回归覆盖分层纹理身份、真实水面、遮挡顺序、完整脚框、精确路径边界、支持区替换及原生点击行走。`test_campus_v12_connections.gd` 默认运行成悦样本；四个 `test_campus_v12_*` 包装测试分别运行南门、东岸、西园及既有区域回归，均会被原生测试入口自动收集。专项诊断仍可设置 `CAMPUS_V12_FIXTURE` 和绝对路径 `CAMPUS_V12_REPORT`。旧脚框测试已经迁移；历史旧版连接样本不作为当前自动验收。

正式 Godot Web 导出、实际浏览器普通入口与移动设备验收分别留证。原生专项、字节身份及导出通过不能替代这些验收，也不能推导为整张校园碰撞已全部校准。具体执行结果和未通过项见本次 PR 说明，不沿用历史试玩测试结果作为当前结果。
