# Canteen machine press presentation

The mixer now presents its existing three shuffled ingredient choices as physical gray-black dispenser controls. One click or keyboard activation presses the matching control, sends that slot's unchanged `c3_mix:<item>` action, shows matching liquid from a fixed outlet, rebounds the control and retires the last drop. This is not a hold-duration puzzle.

## Authority and interruption

- Chapter 3 still validates proximity, light mode and ingredient ownership, consumes one ingredient, judges the original recipe and grants the original result
- The renderer reads accepted before/after facts. It cannot grant an ingredient, choose a recipe or defer its transaction
- Three rapid valid choices commit in their real order and queue only their visual presses. A repeated missing ingredient cannot interrupt the current flow
- Escape, reload, scene change and teardown cancel the visual tail without rolling back or repeating committed inventory
- The existing local `0.75` mixer playback rate and durations remain. Global engine time is untouched
- Reduced motion shows a short pressure change and the accepted fill without continuous flow or falling drops

## Separate visual parts

The existing clean canteen backdrop and original transparent glass are retained. The original gray-black dispenser supplies its backplate, metal frame, nozzle and drip tray. A new reference-guided generated four-pose transparent PNG supplies the moving pressure controls. Liquid layers stay inside the existing glass mask. The cup, machine and nozzle stay fixed.

The existing eight-frame thin bottle dispense animation remains at the ingredient-collection machine. That machine now also exposes its physical pressure control, with rebound aligned to the existing final-drop frame. The thin bottle atlas is not substituted for the mixer's original large glass.

Artwork: `assets/native/canteen_animation/drink_machine_press_4f.png`; unmodified generated bytes, source registration and hash in the adjacent provenance JSON. The atlas is 2172×724 RGBA, with four equal strides of 543 pixels. Runtime source regions are 466×470 at (39 + 543n, 125), scaled uniformly.

Generated with built-in image generation using the actual original dispenser as a visual reference. Prompt requested only one identical grayscale square spring-loaded module in four poses: raised, partially pressed, fully pressed, rebounding. It explicitly required fixed outer housing, neutral tintable pad, genuine transparent background, and no text, bottles, hands or liquid. The generated image is a separate moving component; it does not replace the original scene or counter.

## Verification

Focused tests cover atlas transparency and distinct frames, exact 8/18/68/88% local phase boundaries, selected color and outlet registration, reduced motion, live keyboard/pointer/touch controls, interrupted and repeated flows, rapid input order, completion, controller reward parity and the unchanged local playback rate. These seeded native tests are not a claim of a fresh full-gameplay traversal or physical mobile-device acceptance.
