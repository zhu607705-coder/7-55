# 原剧场箱子的直接操作

用户于 2026-10-24 明确否定「光屑庭院」的收集与强化玩法，认为它不适合《7:55》。该试验停止作为玩法方向；本次改动回到原有的剧场箱子与解谜链。美术和动作反馈可以分别参考，关卡继续围绕观察、推理、操作及验证展开。

## 玩家看到的变化

- 抓住露出的铜片后，铜片沿鼠标或手指移动，并抬高产生真实投影。仍被压住的铜片只会产生少量受阻位移。
- 移开上层铜片会露出原装配草图。已经露出的铜片可直接拖进原来的凹槽；缺口不匹配时退回原位，不会提示正确答案。
- 转柄可以直接拖到轮盘中轴。安装后，转柄的实体轮廓接管拖转输入，轮盘和连杆跟随转动。
- 顺时针转满约 120° 后松手才接受原来的解锁动作。转反或只转到一半，机关返回原位。
- 握住夹层把手下拉，假底板跟着移动。锁舌未松开时会受阻；短距离拉动后松手会复位。
- 完整拉开夹层后，仍须单独拾取荧光粉刷；原通风口、追光游戏与后续剧情保持原来的物品和控制器关系。

原来的点击操作与键盘焦点仍然保留。新动作没有增加道具收集门槛、数值升级、额外物品或剧情分支。

## 输入和状态

`theater_chest_gestures.gd` 识别鼠标/单指抓取，并保留原有的轮廓命中和触摸扩展区域。它向 `theater_chest_contents.gd` 提交临时抓取偏移、高度、转角和夹层开度；三维物体继续使用原来的网格、图案与正俯视投影。

只有松手后才调用原有 `c3_chest_clear/place/turn/open` 意图。角色库存、机关存档、随机会话凭据和所有逻辑判定仍属于原 Chapter 3 控制器，没有新增存档字段。抓取可以用 Esc 取消；移出窗口松手、触摸取消、调整布局、失焦、关闭或替换存档上下文都会释放捕获并恢复已接受的姿态。第二根手指不能绕过尚未提交的转动去打开夹层。

Godot 会先派发触摸生成的鼠标事件，再派发原始触摸事件。本实现只对自己接管的实体部件消耗重复的鼠标事件，其余纸条、拾取、返回控件仍走原来的 UI 逻辑，避免一次点击执行两次。

减少动态效果时仍保留手指对应的直接物件移动，松手后的回弹和就位采用立即完成。正常模式下采用短 Tween 收尾，绘制和动画本身没有进度写入权。

## 验证

新增真实 Main 场景测试 `test_theater_chest_direct_gestures.gd`，通过原读票器进入现有箱子，使用根窗口鼠标和模拟触屏完成铜片、转柄、夹层和粉刷流程。覆盖错误层级、错误缺口、转反、半转、短拉、Esc、触摸取消、窗口外松手、失焦、布局调整、双指、减少动态效果和上下文替换。

原箱内状态、实体体积和完整点击流程也继续回归。当前结果、引擎版本、文件散列及实际窗口截图见相邻验收 JSON。此改动尚未重新导出或发布 Web，模拟触控不代表实体手机验收。
