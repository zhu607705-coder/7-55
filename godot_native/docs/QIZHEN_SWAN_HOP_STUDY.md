## 原有缺口

原八姿态只有较少的收翅、部分展开、全展和下拍状态。
翼根抬起、翼尖展开、蹬水、腹部与脚离水、落水缓冲和逐步收翅都缺少足够的过渡图。
原出场身体始终在水面；没有真正离水的完整姿态和对应落水时序。

## 本轮 16 姿态

折翅浮水 → 前倾蓄力 → 翼根起抬 → 翼尖解开 → 半展 → 接近全展 → 全展
→ 下拍中途 → 蹬水离开 → 空中回收翼 → 短扑最高点 → 下降制动
→ 腹部落水 → 半收 → 近全收 → 恢复折翅。

- 每张是重新生成的完整身体，包含对应翼根、翼尖、颈部、腹部和脚部状态
- 使用身体根部锚点；翼展变大不会自动把鸟重新居中
- 2.52 秒离水，3.38 秒接水。最高 32 源像素；平滑短抛物线只辅助姿态，不替代真实关键图
- 水下部分按水线裁去；离水时露出完整腹部和脚，影子留在水面
- 蹬水与落水各一次水花。水环绘于身体后方，前景水滴独立绘制
- 不把这些展翅姿态混入正常游泳
