## 实施与回归

1. `world.gd` 在实际进入食堂且章节包就绪后创建对象层。图书馆纹理、隐藏开场背景、Room204桌子 PackedScene 在真实使用时加载；原动画、对象拾取、碰撞、信号和事务保持原组件。
2. 包规划取消无条件提升到 core 的食堂根依赖，保留真实 preload 和未知资源保守闭包。同一旧全量包中93项、20,843,662 B移至所属章节。最终新包2531项，core1080项，后续22包；并行新增内容造成总项数变化，不算优化删除。
3. 缓存按每块 SHA 与长度寻址，逐块和整份摘要均验证。旧缓存只在整包身份相同的情况下迁移。本次升级 WASM38块、39,513,091 B可复用；实际新旧 core 没有相同块，首次升级不能承诺只下载一块。
4. WebCrypto异步校验；普通HTTP回退每1 MiB让出主线程。WASM整体校验不额外拼出完整副本。最多三块并发不变。
5. 原控制器所需资源集合不变，前台请求优先，可选预取仅下一章。隐藏页面不启动新可选请求，当前下载正常结束，恢复可见后继续。旧JS host没有窗口能力时关闭可选预取，保留正常按需下载/重试。
6. 移除“食堂必须在首包”的过时断言，保留真实资源身份、完整覆盖检查，并把生产首包回归预算收紧到80,000,000 B。
