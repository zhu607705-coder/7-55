# 第二章图书馆引导规范

玩家进入基础图书馆寻找系统的朋友。在 022 看到书包占座后，当前目标收束为「查明能不能取回 022」。接下来的检索、取证、公示和申请都围绕这一个目标。每次跨页面或跨地点，都由玩家刚看到的证据解释为什么要去那里。

本稿以主线 `73c88a0a` 的控制器、馆藏条目和界面为准。表中的「接棒」是拟采用的引导口径，供文案、配音和 UI 联调；现有机关、证据值、消耗与存档条件以控制器为准。

## 提示在哪出现

| 层级 | 什么时候出现 | 写法和位置 |
| --- | --- | --- |
| 现场接棒 | 第一次取得关键线索或成功完成一段操作 | 由刚操作的物件、页面或角色交代结果与去向。馆藏条目给架位，前台给盖章要求，论坛给公示规则。 |
| 当前目标 | 玩家主动打开任务记录，或读档回来想续做 | 一句「可操作的对象或页面 + 当前目的」。并行取证只列实际缺项，已完成的材料标为可复查。 |
| 操作恢复 | 点错对象、放错材料、条件不足 | 就地写缺什么，以及从哪里补。离开页面后，可在任务记录找回线索。 |
| 短时确认 | 获得物品、记录写入、提交成功 | 用顶部消息栏确认一次。同一结果已有现场动画或剧情反馈时，顶部提示合并或省略。 |

同一刻保留一个主提示。优先顺序是操作反馈、剧情接棒、任务记录。连续剧情结束后再放回操作权，别在动画、对白和顶部消息里同时播三份指令。持续目标由现有的共享任务记录承载，页面只说明眼前对象的用途或操作结果。任务记录可反复看，进度确认只在事实改变时出现。

## 022 主线接棒

| 玩家刚看见或完成的事 | 下一步由什么接住 | 卡住后给到的线索 |
| --- | --- | --- |
| 已预约一层书库 022，到达基础图书馆 | 门口闸机让玩家核对入馆记录，记录里点出一层书库 022 会话未闭合。 | 闸机读过后再进馆，任务记录指向 022。桌牌和书包承担最后的定位。 |
| 022 被书包占着 | 先让玩家发现并拿起旁边的占座纸条。纸条上「临时离座规则详见 CC98」解释开手机的原因。 | 留住纸条上的原词。搜索页保留现有关键词和拖纸条入口，选中对应帖子后记录才更新。 |
| 打开 022 调查帖 | 帖子给出书名。把题名记到任务记录，前往馆内「馆藏检索终端」。 | 可以复查或复制已见题名。搜错书时显示该条馆藏的信息，保留已输入的检索词。 |
| 选中正确馆藏 | 馆藏结果和任务记录使用同一组坐标：基础馆一层、06 架南端上层、索书号 755。架号牌对应物理书架。 | 先提示架号，再提示架端和层位。短拉或取消时，书脊回到原位，可继续抽。 |
| 从书架取出旧版规则 | 在现场读规则。读完才确认，正文列出三类证明，说明公示是恢复座位的前置手续。 | 未读到底时保留书的页内位置和自然滚动反馈，已取到的规则可以重新打开。 |
| 读完规则，开始取证 | 任务记录显示三条并行线：在 022 拍书包、核对相册旧照并把报告交前台盖章；在桌面夹缝取 022 小票；用三份来源去体艺做本人来过补录。 | 打开哪项就补哪项的来源。照片标签过曝时提示检查显示亮度；夹缝反馈先描述小票够不到，再引向能移动它的物件。 |
| 打开体艺补录单 | 每个字段下跟一个来源：入馆记录的两次时间差、调查帖里楼主编辑的公示记录编号、规则列出的证明类别数。网络或更新条件在进入体艺时说明。 | 失败对准需核对的字段，指回已见来源。完成后按真实状态列出剩余材料，材料齐全时指向公示。 |
| 备齐三份证明和规则 | 回 CC98 的同一调查帖，把规则和三份证明放进公示区。界面将「公开材料 4 项」与「申请证明 3 项」分开计数。 | 查看栏显示未上传项，避免让玩家重新收集已归档材料。 |
| 公示上传 4/4 | 由论坛内的置顶说明交代「按上传栏从上到下，给每项证据找一条对应数字回复」。选过的回复显示顺序，可查看或撤回。 | 第一次失败只说来源或顺序不合。反复失败时在上传栏并排给出材料名称与对应信息类别，数字由玩家回看证据得到。 |
| 公示完成，022 恢复入口开放 | 论坛结尾说明接下来打开「图书馆服务 → 022 恢复申请」。提交三份证明后领取解除占座 PASS。 | 申请页标出仍缺的原件，旧规从公示核验。 |
| 拿到 PASS | 任务记录写「回一层书库 022，把解除占座 PASS 用在书包上」。玩家在现场处理书包，再坐到 022。 | 书包提示接受的凭证，座椅提示随当前占用状态切换。 |

## 文案和状态约定

- 一个对象统一一个名称。对玩家使用「入馆记录」「占座纸条」「馆藏检索终端」「022 座位小票」「解除占座 PASS」。地点用架号，馆藏编号用索书号。禁止把两个编号写成同一个地点。
- 同一条引导只承担一个动作。写「去馆藏检索终端查纸条提到的书」时，任务记录应明确题名来自调查帖。像「继续调查」这样的句子，至少补一个可以在当前场景或手机里找到的对象。
- 资料来源随已取得的事实开放。局部失败说明原因和下一次尝试的位置，谜底留在证据里。相机亮度、补录数字和论坛顺序均按这个方式设计。
- 手机用于查帖子、馆藏服务和补录。书架、前台、桌面夹缝和 PASS 使用均以现场物件为入口。暂离当前页面后，提供现有返回现场或回看记录的路径。
- 任务文案从现有事实推导。引导层只读当前阶段和已获得证据；提示播放、重复打开、取消拖拽或回看材料均不产生新的进度。

## 第一轮改动和验收

1. 让书包对白先指向眼前的纸条。现在对白结束时要求「去 CC98」，此时还没有取得打开调查帖要用的纸条。把打开论坛的提示放到取纸条之后。
2. 对齐馆藏结果、任务记录和对白。目前馆藏写「06 架南端上层」，匹配后的对白却叫玩家去「755 号书架背面」。修正文案时同步处理配音。
3. 把规则后的泛化目标拆成三项可回查的材料进度。当前补录成功对白固定说「还差座位小票」，在先取票再补录时会误导。改成只确认到馆证明，下一步由实际缺项决定。
4. 串起「公示 → 申请 → 回 022」。公示与申请的计数和入口都能在原页面读懂。
5. 用普通存档从闸机走到坐下。分别走一遍先取小票和最后取小票，在读规则、提交一半、领取 PASS 后各读档一次。检查重复点击、短拉回弹和错误材料的提示。桌面和触屏都要确认引导没有抢走输入、遮挡对象或指向不可用的入口。
