# 北教独立物件：可运行的调试预览，净地板仍未完成

## 交付范围

7 类真实网页生成的透明 PNG，原始文件保持逐字节不变：105 讲台、书柜、黑板、小公告框、盆栽，以及学生桌、学生椅。24 组桌椅各拆为一桌一椅，合计 **53 个独立 Node2D**。椅子使用网页重新生成的 v2，而非非等比拉伸 v1。

默认与正式导出仍使用主线 PR173（`abd8b0028e8443795518243da7930ee760bc92e9`）已有的墙面/合体桌椅表现。新节点、新 PNG 和新增补底仅在显式 debug 预览中启用。两种配置复用同一碰撞、时态和墙体合成代码；不是第二套剧情或存档系统。

```sh
GODOT_BIN=/path/to/Godot-4.7.1 \
  node godot_native/samples/north_independent_props/run.mjs
```

启动器为子进程设置 `NORTH_PROP_OBJECT_PREVIEW=1`，并建立一次性存档目录。正式 `755_production` 和非 debug 构建拒绝此开关。普通启动不创建独立物件节点。完整运行/捕获说明见 [预览 README](../samples/north_independent_props/README.md)。

## 已验证的边界

- 新旧配置保持同一 24 组位置、48 个桌椅基座、墙体基座、原目标矩形/半径/模式/动作、A2/A3 与存档结构。
- 默认配置 JSON 与上述主线文件 SHA-256 完全一致。以该提交原渲染器为参考，五个时态的墙体合成每一像素、桌椅/墙材质调光与校准碰撞均完全一致。此项是 headless 资源比较，不是新 GPU 截图。
- 独立物件有真实 alpha。原网页母版不修改；运行时丢弃 alpha<0.5，保留像素的基础 alpha 为 1，并映射既定 shared32 后再施加时态/模式调光。
- 两个墙挂物件与墙共用一次 0.78 reveal 合成；桌椅独立按脚点排序。PR173 的墙体精确接触边界保留。
- 任一所需新图缺失，整组预览回退，不能先擦除旧物件再留下空白。
