## 打开与重建

- 正式入口：`godot_native/project.godot` → `scenes/entry.tscn`。
- Mac 可双击 `godot_native/启动游戏.command`。当前本机实测为 Godot **4.7.2.stable.official.ed1daf0bf**、Blender **5.2.2 LTS**；不是口述的 4.7.1。工程保留 4.6 特性基线，打开更新编辑器时会出现升级提示。
- Git 检出先执行 `npm ci`、`npm run native:sync`、`npm run native:media`（需要 ffmpeg）。已生成的源码包包含 `assets/`、`data/source/` 与 Theora 媒体，可直接打开。

- Web 继续使用 `npm run dev` / `npm run build` / `npm run build:demo`。不要删除 `src/`，它仍是原生生成和差分验证的来源。
