# 20261026 北教三层对象接入

本批把北教现有可玩 A1、A2、A3 接入同一套源坐标对象层，并合流 PR177、178、179。正式游戏继续使用现有三张1672×941剧情地图；四栋真实楼宇的历史资料与候选图保留在独立预览中。

| 可玩楼层 | 本批源图对象节点 | 已有独立对象 |
| --- | ---: | --- |
| A1 | 51 | 默认启用53个生成对象：24张桌、24把椅子、5件105教室物件 |
| A2 | 124 | 保留204原家具、残影、桌对象及投影验证 |
| A3 | 144 | 保留301原33节点展柜、抽屉、文献及地球仪 |

源图对象覆盖外墙、窗带、内墙、门梯、花台、公共家具及各房间主要固定设施。每个节点有稳定ID、源矩形、基线、像素优先级和原碰撞归属；不增设交互或存档权威。

## 视觉与算法

- A1不再依赖开发开关启用独立桌椅。分隔墙采用当前时段的原墙顶、踢脚和连续灰泥材质，移除原生成墙面的杂色拼贴；保留原墙脚碰撞及22%人物可见度。
- 源像素使用明确的`pixelPriority`分配重叠归属，各对象从同一不可变时段底图取样。背景仅移除被接管的像素，裁片按原位置、等比、nearest采样重建。
- 固定源裁片标为`movable:false`。裁框含地板或阴影，继续使用原来已标定的前景遮罩；不把整块矩形当物体轮廓盖住人物。没有补全底板的物件不宣称支持自由移动、隐藏或新形状切换。53件生成物、301抽屉和204家具仍使用各自已有的完整素材及运动合同。
- 所有固定裁片先于原控制器的动态门、人物、机关反馈绘制，避免旧门图或家具覆盖已发生的变化。切楼层和时段时成组替换背景与对象。
- 固定对象不逐帧排序或重建纹理；每次有效底图变化才构建一次，复用原纹理。原寻路、脚碰撞盒、逐段扫掠判定和每帧障碍检查保持现有实现。

## 草稿合流

- PR177：四栋一层资料预览、历史来源registry及独立项目命名空间检查。保留原准备、8分片和正式Web验收；资料覆盖不等于18层可玩重建。
- PR178：11件实拍参照候选原始RGBA、来源和哈希。物件位于`art_source`，没有把位置不明的家具强行安到剧情房间，也不加入生产启动包。
- PR179：时间对照、204投影贴合、最后一分钟同步三段只读反馈接入Main；各自只响应已获得事实。原控制器、900ms证明、卡与纸的分别交付保持有效。

## 本地证据与范围

Godot4.7.1的准备、隔离存档、导入解析、启动及原有相关回归采用聚焦运行；现有对象回归新增唯一像素归属和逐像素重建检查，没有另建测试框架。真实GPU截图检查三层、墙面、人物及回切；姿态与镜头来自明确标记的隔离检查点，不是连续通关证明。

按用户要求通过网页版Pro咨询对象归属、补全底板、统一脚盒扫掠和开源复用。采纳可复现的矩形遮人修正，补充不可变源图重建检查；未将无源码的条件性风险当成已发现漏洞。核对[Godot AStar2D](https://docs.godotengine.org/en/stable/classes/class_astar2d.html)与[形状查询](https://docs.godotengine.org/en/stable/classes/class_physicsdirectspacestate2d.html)，本批沿用项目现有有界可见图与精确线段碰撞，不另装导航库。

本地截图和运行收据存于项目外的`755-tools/verification/north-review-20261026`。精确整合提交的云CI、合并、部署和公网验收分别记录；这些本地结果不能代替它们。
