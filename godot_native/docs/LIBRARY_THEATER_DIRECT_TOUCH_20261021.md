# 图书馆、剧场与直接触摸

这轮在独立 Godot 版本内重建场景对象，并增加剧场侧翼排练《借扇成蝶》。它是可退出、可重玩的支线；原演出、启真湖、物品与存档仍由原控制器推进。

## 设计如何递进

三幕复用同一盏灯、道具和接收投影的纱幕。第一幕只有一个位置关系；第二幕让玩家比较同一物件在不同距离的影子；第三幕组合两件扇具，并辨认另一件遮光物。玩家的移动连续改变影子，试演反馈只描述当前差异。失败保留摆放，可撤回整段拖动、重排当前幕，或主动展开分层观察。

题材依据浙大公布的[学生越剧社《梁祝》演出信息](https://www.zju.edu.cn/2026/0515/c79825a3163003/page.htm)和[“以扇喻蝶”的舞台表达](https://zjcm.edu.cn/zyxww/zyyw/201706/2286.html)。本游戏的扇影关卡与舞台是原创设计。研究来源见 [剧场研究记录](THEATER_REHEARSAL_RESEARCH_20261020.json)。

[Touchable](https://github.com/MZhao-ouo/Touchable/tree/5cab3ac2fbde9409814545d66209488304e8b73d)的参考重点是：每段只保留眼前需要的动作，让实体本身承担交互，组合阶段再复用已经学会的关系。具体源码与固定版本见 [输入研究](TOUCHABLE_INPUT_RESEARCH_20261020.json)。本项目沿用自己的 Godot 输入、碰撞、控制器与存档。

## 手机操作

- 手机应用保持竖屏；地图和舞台进入时提供横屏入口，也能选择暂用竖屏。
- 地图点空地行走，点物件沿真实路径走近并查看，双指平移或缩放。
- 湖区直接触摸可见桨，保持原交替划桨与倒划规则。
- 排练拖动实体、点灯试演；长按实体观察，双指轻点撤回，双指按住打开排练单。

地图和排练不再常驻方向盘或操作键。桌面保留键盘与鼠标。路径到达后仍核对原交互距离；换状态、模式、场景、目标、弹窗或失焦会清除待执行交互。首次宿舍触摸移动仍须先安装手柄、获得原移动权限，实际移动后才提交原控制器的手动输入事实。

## 场景对象与门

图书馆清底只覆盖量过的旧物件区域，区域外像素保持一致。书柜、背包、检索终端、打印机独立绘制，座椅与桌体保留各自占地。背包移走后不残留原图副本。

剧场座椅、道具箱、调音台、柜体等按原图轮廓拆分；新素材以原场景为参考逐物件生成。实际网页生成的舞台灯使用透明 PNG，统一缩放后接入排练。提示词、原始输出摘要、最终文件摘要和消费者见 [素材来源](LIBRARY_THEATER_ART_PROMPTS_20261020.json)；开场与完成文案来自[网页 High 修订](THEATER_REHEARSAL_COPY_PROVENANCE_20261020.json)。

图书馆玻璃门与剧场门的可见门叶参与真实碰撞，感应区内有人时保持开启。剧场离场先等待门可通行，再让角色穿过门口，最后调用一次原出口动作。门和动画不直接写剧情进度。

剧场通往启真湖的原全景为 `13668×1084`，超过部分浏览器的纹理上限。运行时将它无损分为七张不超过 `2048` 像素的纹理，按原源像素坐标绘制；地图尺寸、碰撞与压缩通行数据保持原样。同源剧情插图也使用分片显示。`native:sync` 自动重建分片，网页包以分片替换原大纹理，避免重复下载。
