# 扇影排练：开合、远近与共用灯源

2026-10-24。回应“前面的扇子交互太简单”，在现有《借扇成蝶》三幕里加入连续开合和共用灯源。保持原扇架入口、可选排练及独立梁祝演出；不另建存档，不发道具，不将演出动画当作过关依据。

## 实际玩法

1. 第一幕从收拢的扇子开始。移动底座只能对齐影子位置，还需要拉开外侧扇骨的铜扣，让翼缘展开。
2. 第二幕同时比较上下边缘和翼面宽度。前后移动改变投影整体尺寸；扇骨开合改变展开宽度，只靠拖动底座无法满足两个条件。
3. 最后一幕先观察固定木钉的影子与幕上红刻线，移动舞台灯校正光路。灯会同时影响两把扇子和侧幕的投影，不能只顾一侧。
4. 移开遮光的侧幕；再比较两把大小不同的扇子，分别调整距离、位置和开合，让双翼在同一处合上。玩家可以用任何合法顺序求解，不强制观察点击、不以动作次数判定完成。

## 输入与动画

- 鼠标/手机横屏：拖底座移动，拉扇骨铜扣开合，第三幕拖灯改变共同光源；点灯试演、换幕与收幕。没有底部“演一遍/下一幕”操作栏。
- 键盘：Tab 选物，方向键/WASD 移动；Shift＋左右键开合；空格/Enter 点灯试演，Z 撤回，R 重排。
- 扇面由十片纸叶绕同一扇轴展开，铜扣与热区使用同一几何；纸叶、扇骨、木底座和拖动后的投影实时变化。换幕有短收幕过渡；失败闪示实际不合处；成功灯光微亮。减少动态效果保留静态反馈和原判定。
- 操作说明集中在初次排练单和“观察”；常驻舞台只留当前幕名称。触控铜扣热区至少44屏幕像素。竖屏手机保留旋转和返回入口，不运行缩小后的场景拖动。
- 暂停、失焦、旋转、触摸取消清理旧手势；一整次拖动可一起撤回。开合与移动灯源也进入撤回历史。
