# 扇影排练：开合、远近与共用灯源

2026-10-24。回应“前面的扇子交互太简单”，在现有《借扇成蝶》三幕里加入连续开合和共用灯源。保持原扇架入口、可选排练及独立梁祝演出；不另建存档，不发道具，不将演出动画当作过关依据。

## 实际玩法

1. 第一幕从收拢的扇子开始。移动底座只能对齐影子位置，还需要拉开外侧扇骨的铜扣，让翼缘展开。
2. 第二幕同时比较上下边缘和翼面宽度。前后移动改变投影整体尺寸；扇骨开合改变展开宽度，只靠拖动底座无法满足两个条件。
3. 最后一幕先观察固定木钉的影子与幕上红刻线，根据木钉影的两端刻线，左右移灯校正位置、前后推灯校正长度。灯会同时影响两把扇子和侧幕的投影，不能只顾一侧。
4. 移开遮光的侧幕；再比较两把大小不同的扇子，分别调整距离、位置和开合，让双翼在同一处合上。玩家可以用任何合法顺序求解，不强制观察点击、不以动作次数判定完成。

## 输入与动画

- 鼠标/手机横屏：拖底座移动，拉扇骨铜扣开合，三幕都可左右、前后拖灯改变共同光源；点灯试演、换幕与收幕。没有底部“演一遍/下一幕”操作栏。
- 键盘：Tab 在扇架、灯、节目册、侧幕绳扣及退场幕缝间选物，空格/Enter 操作当前物件；方向键/WASD 移动道具或台灯，Shift＋左右键开合，Z 撤回，R 重排。Esc 打开临时排练单。
- 扇面由十片纸叶绕同一扇轴展开，铜扣与热区使用同一几何；纸叶、扇骨、木底座和拖动后的投影实时变化。换幕有短收幕过渡；失败闪示实际不合处；成功灯光微亮。减少动态效果保留静态反馈和原判定。
- 排练顶部操作栏已移除。点击桌上的节目册读取观察线索，点按或短拉右侧幕绳进入合演，点击左侧幕缝退场；合演内通过侧台谱架上的节目册读取动作线索。合演的节目册避开人物接扇热区，纸页、绳扣与侧幕有对应动作反馈。
- 初次排练单说明操作，节目册逐页提供线索；常驻舞台只留当前幕名称。新物件和铜扣触控热区至少44屏幕像素。竖屏排练保留旋转和返回入口，禁用缩小场景的操作。
- 暂停、失焦、旋转、触摸取消清理旧手势；一整次拖动可一起撤回。开合与台灯的两个坐标一起进入撤回历史。点击台灯试演保留原道具选择；开始拖灯后才切换到台灯，避免打断键盘调整扇子的连续操作。

- 暖色光束从台灯镜口延伸到纱幕，幕上亮区随灯位和灯距改变；扇影、遮光侧幕影和木钉影共用模型投影。台灯底部短轨表示两轴行程。所有刻线都在纱幕内，超出纱幕的影子被裁切。

## 权限与回执

`theater_shadow_rehearsal_model.gd` v3 统一计算几何与逐步输入回放。投影中心为 `lampX + (objectX - lampX) * m`，其中 `m = (screenDepth - lampDepth) / (objectDepth - lampDepth)`，目标分别约束中心、高度与开合。第三幕木钉影子同时约束位置和长度、侧幕遮光和双扇匹配都由模型检查。完成仍交给原 `theater_rehearsal_session.gd` 的一次性会话校验。旧布局回执不匹配新摘要；没有持久排练数据需要迁移。

舞台背景、桌椅和梁祝人物沿用现有原创素材与骨骼规范；纸扇、节目册、谱架和幕绳是新增原创程序几何，不引入第三方图像或模型。原54秒演出、人物腕点挂扇、移动端QTE与存档语义保持原有边界。
