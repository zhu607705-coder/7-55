# Photo-led source backup, 2026-11-03

This checkpoint preserves 68 independent candidate assets recovered from retained delivery packages and the subsequent evidence-led instrument/composition batch. It is based on the real PR 210 repository tree. The recovery snapshot is not repository ancestry.

The backup itself does not install these objects into the building viewer. Scene integration and the user's requested sofa, monitor/mouse scale, desk-material, and third-floor passage corrections follow separately in this work branch. Room 304 is not identified by the existing layout data and must not be assigned by guessing. Earlier spatial browser acceptance remains blocked by a 30-second ordinary-navigation timeout; this source backup does not resolve that blocker.

## Contents and privacy

Independent editable Blender sources, source LODs, plain/Draco runtime GLBs, generation scripts, provenance, and bounded validation evidence are included. Private reference photos, identification crops, people and original certificates are not distributed. Private source IDs are replaced with non-locating source tokens; source photograph hashes remain for provenance. `photo_publication_sanitization.json` records exact before/after source hashes. Geometry and embedded synthetic texture bytes are unchanged by that metadata-only transformation. Six affected runtime manifests carry the transformed source/runtime hashes.

Historical validation reports describe the recovered bytes and their original execution. They are not assertions that the building integration or a new browser run passed. The prior 20-asset batch recorded 5,834 checks without failures; browser interaction still requires current-source testing.

## Compressed editable review scenes

Only three large, reproducible review compositions use lossless `.blend.gz` storage. Individual asset `.blend` files remain directly editable. `photo_backup_archives.json` lists the exact decompressed SHA-256 and byte size. Decompress an archive with `gzip -dk path/to/file.blend.gz`, then open the resulting `.blend` in Blender. The archive has been round-trip checked against the original editable scene. The original source snapshot remains untouched.
