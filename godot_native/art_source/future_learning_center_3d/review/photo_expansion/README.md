# 新照片候选：休闲、工具车、打印与荣誉展示

这一批依据用户2026-11-03新提供的8张照片制作。输入照片已逐张查看，不作为纹理或原件放入交付包。重复视角和相同设备使用同一资产的多个实例，不按照片数量复制源模型。

## 本批分组

- photo_lounge：橙色单人休闲椅、同家族双人椅、白圆几、灰色短背吧椅、细高方凳、窗边窄木吧台。
- photo_workshop：绿色轮柜、真实方孔背板、蓝柄螺丝刀架、红色扁箱、黑箱红卡扣、小台钳。
- photo_print_honors：白色多功能打印机、黑色低矮打印机、荣誉展示柜、浅木相框、证书立架、奖杯轮廓。两台同类白机共享一个源模型。

实验室中心桌全景和电子仪器墙仅用于识别相邻结构与后续布局，本批未逐台复原其中所有仪器。新照片不含微波炉/冰箱额外视角，因此厨房定向纠正继续依据之前的两张近景。

## 真实性与隐私

全部尺寸为照片比例下的建模估计，没有标尺或厂家CAD。隐藏机构仅作闭合简化，不提供承重、设备性能或安装尺寸。打印机显示屏保持无文字；照片中的姓名、人物合影、证书内容、二维码和品牌标识均未投射到模型。

荣誉柜只复原展示结构及框体，内容面是明确的可替换中性占位，不是伪造证书或奖项。后续需要显示真实内容时，应单独指定获准使用的图片。

每件提供Blender4.3.2源、三档源GLB、普通GLB及Draco GLB。纹理为合成的小图，嵌入GLB并打包到blend。舞台、灯和相机不进入单件资产。组合图为CPU渲染，不是网页或正式Godot验收。

## 验证

锁定依赖安装后，在完整工程艺术源目录运行：

- node pipeline/build_photo_expansion.mjs
- node pipeline/test_photo_expansion.mjs

每组验收有明确6件清单，检查三LOD来源hash、实际网格边界、法线、退化面、材料、嵌入资源和直接解码的20-bit Draco位置量化。保留优化前后包络误差和压缩误差，不把源简化误差冒充编码误差。

工具背板的432个孔是真实几何，源/普通GLB/Draco每级均逐孔检查通孔和周边板材。为保留孔和窄边，部分模型高于通用20k/8k/2k三角预算，报告记录实际数量，不声称达到预算或已经证明网页流畅。场景实例复用、可见性和最终帧率需在集成阶段单独验证。

本轮不修改主建筑、正式场景互动、Godot、签到对白或太阳能页面，也不自动上传工作分支。
