# 中央实验桌与电子工位候选

这是同一批八张用户照片中，第3张中央实验桌和第6张电子工位的近景重建。参考原件仅用于观察，不嵌入模型或交付包。台面尺寸、格架间隔和设备大小为照片比例估计，并非实测。

## 建模范围

中央实验桌保留可见的浅木薄台面、四方腿、黑办公椅和开放格架。显示器及输入设备优先复用已有独立资产。遮挡严重且不能确认形体的仪器不作精确复原。

电子工位保留厚木台面、灰色抽屉、后部孔板和搁架、绿色工作垫，以及可见的仪器外壳。仪器仅有外壳、空白黑屏及可见旋钮/按钮轮廓，不表示具体型号、参数、功能、可用连接或测量读数。

组合布局记录复用对象ID与变换，不把多次实例重复导出成多个源。旧资产不覆盖；需要变色时仅在组合中记录材质覆盖，不把非等比拉伸当作新型号。

## 交付边界

每个新增资产包括Blender 4.3.2可编辑源、三档源GLB、普通GLB和Draco GLB。组合图使用CPU渲染，不是浏览器或Godot画面。近景候选未替换主场景。

验证报告区分源模型简化误差和Draco编码误差，记录实际三角面数。已有真孔板可复用，但其高面数仍是后续网页集成的性能风险，不因为当前CPU渲染成功就视为通过网页验收。
