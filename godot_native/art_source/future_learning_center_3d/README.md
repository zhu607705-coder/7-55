# 未来学习中心 · 米制模型与第一人称漫游

2026-11-01。此版本把整层总览、房间近景和第一人称行走放在同一套米制几何中。镜头代表观察者，不需要人物或手部模型。它是独立的建筑评审网页，尚未接入正式游戏。

启动网页：

```sh
python3 -m http.server 8142 --bind 127.0.0.1 --directory web
```

- 办公室第一人称：<http://127.0.0.1:8142/?floor=3&room=studio_1&mode=walk>
- 四楼整体：<http://127.0.0.1:8142/?floor=4>
- 实验室：<http://127.0.0.1:8142/?floor=2&room=formula&mode=walk>

电脑拖动画面转头，WASD/方向键行走。触屏左下摇杆移动、右侧拖动转头，支持两个触点同时操作。返回总览、切换楼层、房间聚焦和楼层展开均可逆。实验桌上的卡尺、螺丝刀可以点选近看，返回后恢复原观察位置。说明仅在请求时打开。

## 同一套尺度

模型、网页和碰撞均以米为单位。总览只剖切墙体、隐藏天花并改变镜头距离，室内和工具几何不会为不同视角单独缩放。

## 建筑证据与范围

前一版独立网页的目录在本轮文件系统中不存在。本版本恢复了聊天记录中保存的源像素描图：2F6个封闭区、3F8个封闭区、4F7个封闭区；不等同于原游戏25个房间/功能区的完整重建。原游戏的放大像素坐标没有用于推导米制尺寸。源矩形、中庭多边形、门面方向和恢复依据见 `sources/plan_trace.json`。

建筑水平范围沿用约26.1×42.4m的面积校准；2F研讨室约66.1㎡，3F工作室1约24.8㎡。这些是描图与面积标注的近似，房间净面积、墙厚、门窗和高程仍待核对。层高暂用4.05m。1F展厅归属已确认，但缺少整层边界，未虚构一楼布局。当前楼梯为结构示意，不支持沿踏步连续跨层；跨层请返回总览选择楼层。

灰色隔板、网背椅、柜体、桌面物件和茶水区只作为可继续细化的几何；摆放数量不代表已核验的现场设备清单。本轮着重解决进入房间后的尺度、真实孔洞与可行走性。

## 可编辑与可复现文件

- `flc_walkthrough.blend`：Blender5.2.2LTS源文件，单位为米；楼层与桌椅、工具均可独立编辑。
- `scripts/build_scene.py`：可复现建筑和共享尺寸组件的生成器；重复家具使用链接网格。
- `web/assets/building.glb`：glTF2.0交换与展示模型，未对观察模式另设缩放。
- `web/assets/layout.json`：同源房间、门口、碰撞与中庭数据。
- `web/`：本地分发的Three.js0.185.1网页，无CDN依赖。Three.js保留MIT许可证。
- `review/`：最终浏览器截图、模型/碰撞/输入验证和界面审查记录。

重建与验证：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/build_scene.py
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/check_model.py
node scripts/test_collision.mjs
node scripts/test_browser.mjs
```

浏览器测试使用本机Chrome和`/private/tmp/flc-viewer-qa/node_modules/playwright-core`；移到其他机器时调整该依赖路径。此测试路径不属于网页运行依赖。
