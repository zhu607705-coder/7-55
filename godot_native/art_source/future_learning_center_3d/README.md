## 建筑证据与范围

前一版独立网页的目录在本轮文件系统中不存在。本版本恢复了聊天记录中保存的源像素描图：2F6个房间/区、3F8个房间/区、4F7个房间/区（含连通开放办公区）；不等同于原游戏25个房间/功能区的完整重建。原游戏的放大像素坐标没有用于推导米制尺寸。源矩形、中庭多边形、门面方向和恢复依据见 `sources/plan_trace.json`。

建筑水平范围沿用约26.1×42.4m的面积校准；2F研讨室约66.1㎡，3F工作室1约24.8㎡。这些是描图与面积标注的近似，房间净面积、墙厚、门窗和高程仍待核对。层高暂用4.05m。1F展厅归属已确认，但缺少整层边界，未虚构一楼布局。当前楼梯为结构示意，不支持沿踏步连续跨层；跨层请返回总览选择楼层。

本轮按照两份飞书正文修正功能：4F采用18/12/10席的A/B/可选C开放办公、80格个人柜、三种研讨布局和干燥耗材存储；3F北侧按用户现场照片补入上下窗带、约6.2m局部高天花及移动展台/圆角桌/格柜/绿植，另有摄影录播、吧台/高桌/交谈/休息组合；2F机电实验室分电工和机加工区，增加玻璃隔断、ESD台面和设备。柜体、摄影器材细部与设备摆位仍是可审核设计近似；采购计划数量不能冒称现场库存。

**四楼尚未完整复原**：西南正式大会议室的可靠轮廓尚缺，文档自身的4F图注也说明空间对应不正确。原有数字描图不能替代核准墙线；本轮没有虚构该室边界。X-Lab、考拉子方案与全部机加工设备仍待补齐。

## 可编辑与可复现文件

- `flc_walkthrough.blend`：Blender5.2.2LTS源文件，单位为米；楼层与桌椅、工具均可独立编辑。
- `scripts/build_scene.py`：可复现建筑和共享尺寸组件的生成器；重复家具使用链接网格。
- `web/assets/building.glb`：glTF2.0交换与展示模型，未对观察模式另设缩放。
- `web/assets/layout.json`：同源房间、门口、碰撞与中庭数据。
- `web/`：本地分发的Three.js0.185.1网页，无CDN依赖。Three.js保留MIT许可证。
- `review/`：最终浏览器截图、模型/碰撞/输入验证和界面审查记录。

重建与验证：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/build_scene.py
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/check_model.py
node scripts/test_collision.mjs
node scripts/test_browser.mjs
node scripts/test_source_views.mjs
node scripts/test_furniture.mjs
```

浏览器测试使用本机Chrome和`/private/tmp/flc-viewer-qa/node_modules/playwright-core`；移到其他机器时调整该依赖路径。此测试路径不属于网页运行依赖。

## 本轮验证

当前修订：模型37项、通路88项、常规浏览器36项、需求对应视图17项、桌椅及照片专项15项全部通过。完整结果与模型哈希见 `review/validation_summary.json`。校验覆盖GLB真实尺度、中庭孔洞、全部房间/区进入同一通路、机电隔断通门、东侧开放区连接，以及实际浏览器键鼠和模拟双触点输入。

浏览器模拟触屏，尚非物理手机、Safari/Firefox、现场尺寸或完整视觉验收。测试通过不代表缺失空间已经建成。

本地参数化几何是本项目的新作；生成器代码沿用项目源代码许可。厂商资料只是尺寸出处，其文档、商标及原始CAD的权利没有被重新许可。NVIDIA候选仍保留数据集CC BY4.0出处，下载后需核对具体包内依赖与归属。原楼层参考资料的权利仍归原所有者。
