# 字流终端 · 2026-10-22

用户明确修正方向：小 ASCII 字符组成汉字；黑底终端；用密集的连续流动显字，而非稀疏雨点和独立字块。

参考图仅用于布局和密度判断，均处于 `.gdignore` 的 art_source，不作为底图打包进游戏。游戏文字和交互保持原生可动画对象；不将示意图中的按钮或文字烘焙成玩法。

运行时：近黑 `#070B10`，输出面板 `#0B1219`，冷白 `#DBEDF4`，冷蓝 `#9AD9EF`。背景微字格4×6、95%占位；汉字笔画内使用仍可辨识的3×4最小字格，全占位，单位面积密度两倍。组成字形的小字符从上下左右四侧汇入，在0.28秒内落入固定笔画，之后随大字下行，背景也持续有四侧来流。字形20×20采样，汉字80×80逻辑显示，双字间隔5。可碰撞词体使用同一尺寸计算和16像素水平余量、92像素高度，原有窗口、运动、扫掠检测和语义校验保留。线索拆成最多四字的短词组，在两列连续下落，和可碰撞目标共用同一ASCII笔画。66个汉字采样、8个shader形状槽（2个物理词、6个线索词）支持这层词云；线索以44px字高、较低亮度出现，在窗口上方淡出，目标保持80px高。正常流动中不再叠加普通字体的线索句。原阅读等待与目标生成时机不变，字流的独立呈现时钟跨这些阶段连续前进；暂停与回看才停止。shader 使用活动自身时钟，不使用持续走动的 TIME；暂停、回看和减少动效仍有效。

小剧情字和功能控件保持清晰字体与至少4.5:1对比度，空白阅读区用于遮住密集字流而不出现浅色卡纸。此前已确认的签到成功羊皮纸和打印时间保持原样；终端从坐标错误及拦截阶段开始。

ASCII位图图集与汉字采样均源于项目既有 Fusion Pixel 字体（OFL-1.1，原许可见 `assets/rpg/fonts/licenses/FUSION_PIXEL_FONT_OFL.txt`），生成工具 `tools/build_prologue_ascii_masks.py`。原6×8小字符图集在4×6格显示，细3×4图集通过2×2覆盖采样保留细笔画，避免直接缩小时漏笔画。源码和shader为项目原创，没有复制 ascii-sharks 源码或鲨鱼图形。

完整可恢复性与验收见 `docs/PROLOGUE_TERMINAL_DENSE_20261022.json`，包括准确源码指纹、真实导出、键鼠/触屏模拟和录像证据。

后续入口调整：`再试这段字流`和`重看完整线索`为148×34、15px字的右下角控件，逻辑右距16、底距14。失败帮助在同一列上方，回看关闭控件复用右下角位置。ERROR窗口使用同套像素字体、细框和冷蓝标题，窗口真实物理尺寸不变。

最新用户修正：上面的右下角重试/回看/帮助方案已撤销。活动原生字流不再呈现失败说明、重试、完整线索入口或底部常驻说明；失误自动继续当前阶段，仅重发未收集目标。显式系统暂停和减少动效保留。上述参考图与旧入口描述仅为过程记录，最终验收见 `docs/PROLOGUE_CLEAN_FLOW_20261022.json`。
