# 20261103 共创平台与账号云存档整合

本次基于 `main` 的 `72fe2ed3dab84c99cedb2e427a4d639fca135472`，在独立功能分支交付代码。保留上游当前开场、未来学习中心、晨札字体、Godot 4.7.1 和原生分片检查。GitHub 代码交付不等于合并或公网部署。

## 实现范围

- `platform/` 独立管理共创页面、API、Authing 会话、PostgreSQL、追加迁移与测试；游戏不导入平台运行时，平台不导入游戏剧情运行时。
- 游戏入口、手机控制中心和设置菜单提供共创、玩家账号及存档管理；游戏内账号面板使用项目像素字体和配色。Authing 的托管登录表单仍由 Authing 配置，不属于本地像素面板。
- 同站游戏和平台复用同一玩家会话；每账号一条主进度、上一份有效备份、重开前备份。个人编辑和照片随存档同步，归属由服务端会话确定。
- 游客带入和并发冲突须明确选择；账号游戏断网或身份变化后暂停；版本比较和操作编号防止旧请求覆盖及重复写入。
- 兼容当前原生 v36，旧 v35 的云档复用原生字段迁移，未来格式拒绝覆盖。运营身份不获得读取其他玩家存档的入口。
- 控制中心新增入口合并为一行，窄屏使用“存档 / 共创 / 账号”短标签，保留保存、导入导出、重开和截图的操作空间。

## 交付边界

- 功能分支与合并请求交付；远端检查以 PR 页面为准，不自动合并、发布 Pages 或部署服务器。
- 不上传 `.env`、密钥、玩家档、数据库、备份、工具下载、导出包或测试截图。测试使用隔离数据库 schema 和浏览器缓存。

- 实体手机、两台真实设备、真实玩家账号的生产云存档、全章节人工游玩及服务器备份恢复仍需上线验收。
