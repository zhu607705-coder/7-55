# Authing 托管登录页样式

`authing-pixel.css` 只改变登录、注册、找回与补全页面的外观，不添加 JavaScript，不改变账号字段、协议、回调或权限。文件内含现有 Fusion Pixel 字体的改名子集及完整 OFL 许可证；用户输入中未包含的字形使用系统字体。

在 Authing「品牌化 → 全局登录框 → 样式配置」的自定义 CSS 中粘贴完整内容。新版控制台可能称为“整体样式”。先保留已有 CSS；如果已有其他项目配置，不直接覆盖。保存后从平台重新发起登录，核对电脑和手机尺寸，并检查注册、找回和补全页面。若控制台提示套餐权益不足，停止，不购买升级。

官方入口说明：https://docs.authing.cn/v2/guides/customize/global-guard/
