# 755 米校园特技追纸

当前开发预览将原来的固定换道追逐改为特技和道具玩法。正式进度仍由 ChapterThreeCanteenController 校验到达755米及剩余机会，临时的特技、道具和动作状态不写入全局物品栏。

## 操作

- 点击“上车追纸”开始；A/D 或左右键按住连续转向。
- 按住Space蓄力，松手起跳。轻点是短跳，蓄力可越过较高障碍，空中不能再次凭空起跳。
- J响铃。车铃有2.6秒冷却，能够震开近处部分自行车、路人和路锥；实心横栏仍需要跳跃或调整路线。
- E使用拾取的道具：餐盘护具抵挡一次碰撞；顺风纸团提供短时加速。
- 彩色跳台提供可选的飞跃路线。飞越、擦身和有效响铃累计奖励，连招可带来短时加速；每到一段补给恢复一次机会，上限3次。
- 手机提供转向、起跳、响铃和道具按钮，支持同时按住方向与蓄力按钮。

## 规则与显示

ChaseStuntModel统一管理连续横向位置、速度、跳跃高度、碰撞、道具、车铃冷却、清除物件和完成状态。Three.js读取同一个位置和高度，显示腾空车辆、车铃波纹、餐盘保护、跳台、发光道具和主动变线的纸条。Canvas能力回退仍显示必要的跳台、道具与技能反馈，但不作为3D视觉验收证据。

ChaseRoute只提供755米与四段场景的位置元数据；当前速度由动作模型决定，不再固定为90秒。开局、失败重试、页面隐藏暂停和终点转场均有明确操作状态。失败只记录本次尝试；“再骑一次”恢复起点与3次机会。到755米且仍有机会后由章节控制器记录成功并进入原来的下一阶段。

## 验证入口

- `npm run canteen:validate-stunts`：连续转向、跳跃、禁止二次空跳、车铃冷却、真实清障、道具获取与使用、暂停、单次结算、重试和30/60/120Hz可完成路径。
- `node scripts/verify-canteen-chase-model.mjs`：正式GLB来源、角色骨骼与车辆接触、基础障碍及场景元数据。
- 开发入口：`http://127.0.0.1:4182/?devCheckpoint=c3-canteen-chase`。
