## 可体验范围

从原南门出生点出发，沿原有铺装主线到 `[760,877]`，现在可继续走到东侧直路 `[769,807]`，再到北侧路口前 `[733,683]`。本轮源图检查到 `[731,676]`；这个端点只是当前工作范围，不能理解为现实中的门、墙或通行限制。

- 新增一个按可见路缘描出的 28 顶点铺装多边形，原提案轮廓未缩窄
- 新增 485 个原生导航网格点，485 个都与真实出生点相连
- 原 41 个导览点、3 个 POI、南门出生点保持不变；A/B 仅是测试停点
- 使用原共享学生：18 源像素高、脚半径 3、默认速度 88；按碰撞后的实际位移推进步态
- 原画、全部原建筑脚线、当前图书馆的实际东侧脚线、第一教学楼和共享学生资源保持字节不变
- 无室内、无新树干、无森林碰撞、无新增 TileMap；这是原画道路扩展

## 脚下判定

已有代码检查脚点及上下左右 3 像素。原生反例表明，新增接入口脚点 `[763.25,881]` 虽通过这五点，实际圆形脚仍有 31/128 个圆周样本越出铺装，而原生建筑/树干碰撞没有接触。

本补丁仅对新增权限增加圆形检查：原铺装和新增道路先取并集，再提取 40 条外露边界段；脚圆必须与外边界保持半径 3 的距离。内部重叠边不参与检查，接缝不会被逐个多边形二次侵蚀。导航和实际移动共用同一个判据。原先已允许的脚点仍保留原行为。

## 原画前景

只从原图提取 798 个叶片像素，分成 9 个局部前景段。东侧林缘和西南转角可辨树冠参与遮挡。西侧楼边低草/低灌木没有被当作盖住人物的高前景。文理楼仍用现有独立原画对象和原深度锚点。

叶片段不创建物理体。下缘深度属于对艺术图的视觉估计，不推断树干位置或现实树高。人物肩部投影到平坦草地不影响脚下通行。

## 继承限制与保留的失败

1. 局部原导航边上保留 86 个圆形退让或旧缝问题采样点。这是采样数，不是 86 条独立缺陷。本补丁不借此重写旧导航
2. 初次 headless 40/41：旧边 `[751,865]→[751,867]` 的 `[751,865.75]` 被测试误归入新增权限。原数据和代码没有为通过测试而变动；分类改用原完整边的存在性，包括对角边原侧格。原始失败和坐标仍在证据中
3. 早期 20 个路边站立 GPU 姿态没有触到叶片。这些结果只能证明无不必要遮挡，不能冒充叶片交叠证据；实际行走帧补测另行报告
4. 截图 A 的右侧灰色地图外边来自既有相机边界表现，本补丁没有调整相机或 UI
5. 图像字节未改；GPU 原渲染像素比较是固定局部视窗比较，不是新一轮全校园渲染认证
6. 这是游戏艺术地图的有限室外通行扩展，不是测绘、现实公共通行保证或全校道路认证

## 复现

在仓库根目录、已完成常规 Godot 资源导入的环境中：

```sh
node scripts/check-buct-changping-east-road.mjs
# 已接入既有 BUCT 测试入口（完整入口会检查其他校区）
node godot_native/tools/test_buct.mjs --source-only
bash scripts/test-buct-changping-east-road.sh "$PWD/godot_native" headless
bash scripts/test-buct-changping-east-road.sh "$PWD/godot_native" proof
bash scripts/test-buct-changping-east-road.sh "$PWD/godot_native" leaf
```

不要并行运行多个 Godot/GPU 实例。测试会把所有 TMP 和 XDG 目录放在当前工作目录下，并保留证据。`proof` 需要已存在的桌面；不会启动 X server。`leaf` 是短时合法脚点+真实行走帧遮挡补测。

运行时入口仍是原北化昌平场景。无需修改浙大故事入口或生成整仓库 PCK。
