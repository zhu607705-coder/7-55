# 昌平文理楼：独立外观对象

## 范围与来源

本批仅处理文理楼一栋自然相连的庭院建筑。中央低屋顶、连接廊、北翼、东西翼及南侧立面属于同一个可选中对象。旧四片 UV 不是楼体的完整轮廓，不能简单合并它们得到庭院遮罩。

- 原校园图：950 × 1656，SHA256 `f92a8de6ef703bab4b2e471a49acc082dd4d128d264d99d3ed1818fdb0c93707`
- 实际参考裁片：`[657,735,109,110]`，SHA256 `e91ff5191d5e6673c0421b3099256f152357425a8821c1819af54a3d04a2944c`
- 楼体原下载 PNG：1230 × 1278，真 RGBA；SHA256 `29acba79fa0ba17512350d3db377a6b8e2f675ef683f59754d305e2dc04f6afc`
- 净底原下载 PNG：1249 × 1260，RGB；SHA256 `06cdc5eeb93f1d60eccd732bbaec3b0abcd3958926cee08cb106518c1ee40990`

两张下载原件逐字节保留。没有重绘周围地图、换人物或开启室内。没有新导航区域、真实入口功能或新导览目标。文理楼卡只提供外观识别；原三处导览 POI 保持不变。

## 配准与独立性

楼体使用一个正的等比缩放 `0.08707916874086201` 和平移 `[654.170110833,735.708489019]`，无旋转或非等比拉伸。九组屋顶与立面特征的坐标均保存在注册数据中；拟合 RMS 为 1.258 个源像素。不同生成边沿与模糊源图仍有局部像素级差异，不能把它称为测绘模型。

原四个楼体 UV 子节点移除，原三个 `StaticBody2D`、碰撞多边形及变换逐点不变。由新 PNG 的实际 alpha 决定选中。庭院透明不会产生行走权限。中央屋顶源点 `(704,782)` 必须仍为实体；三处高置信庭院核心 `(697,769)`、`(723,779)`、`(692,791)` 必须透明。

底图中的原楼通过独立的原坐标所有权遮罩清除。遮罩不是旧四片 UV 的并集，也不是生成楼体 alpha 的简单缩放。它包括中央实体，并明确保护可确认的庭院核心和遮罩外像素。局部屋顶边沿的六个复核源像素另列为精确行段；其中一个本已覆盖，净增加五个清除像素。

净底只采原生成图的无新增树铺装区域 `[360,380,600,600]`，等比映射并仅在原楼所有权遮罩内显示。采用固定 0.75 明度的推定阴影。隐藏楼体时看到的是推定补底，不是真实院落平面；不会把生成图扩展出的周围树冠带进原地图。原图和水面 material 的所有权不变。

## 显示脚线与物理脚点

五类显示表面分别为北翼、西翼、东翼、中央低屋顶、南侧前翼。每类有独立的逐列地面接触深度，不能统一采用南楼底线。显示表面与物理脚点完全分离。脚线变化只分配互补渲染区间，不改角色位置、碰撞或可行走范围。

- 原 PNG 的 RGB 使用 mipmaps，alpha 固定读取 LOD0
- 实体 alpha ≥ 0.97 置实，消除原生成 PNG 约 252/255 的实体漏底
- alpha < 0.04 丢弃；显示与拾取使用同一 alpha 下限
- 每个原 texel，包括透明邻域，都保留确定的表面 ID，避免双线性 alpha 边缘被 ID=0 误丢弃
- 公共 RGB LOD 按实际 canvas 缩放更新，并进入静止角色的早退判断；缩放时角色无需先移动
- 所有文理楼 pass 使用同一源坐标 quad；Y-sort 节点只承担排序，避免浮点抵消让 0.97 alpha 阈值在 247/255 与 255/255 间跳变
- 原有图书馆及一教 shader 不变

CPU 原坐标 alpha 相交核验：十个既有树冠和九片东路原叶边与新楼均无交集，因此本楼不需要额外静态足点区间。两张共享原纹理的互补 pass 足够。

## 验收命令与边界

注册字段与两个二进制遮罩可由 `python scripts/build-buct-changping-wenli.py godot_native` 复现（Pillow + numpy；不修改 PNG 原件）。

`node scripts/check-buct-changping-wenli.mjs`

`bash scripts/test-buct-changping-wenli.sh godot_native headless`

`bash scripts/test-buct-changping-wenli.sh godot_native proof`

测试 TMP、TEMP、TMPDIR 与 XDG config/cache/data/state/run 全部落入指定工作目录。一次只启动一个 Godot。GPU 夹具包含完整 PNG 对照、每个脚线区间、静止缩放、实际学生遮挡、原坐标净底边界和正式地图截图；特殊离路脚点仅用于测试，不新增路线。

原相邻已合入建筑的隐藏局限不在本批修复范围。本批不声称完整故事回归、Windows 实际运行或手机真机验证通过。

## 本轮已核实结果（2026-10-13）

- 原生 GPU：29 项，0 失败。五个角色脚点、静止缩放 2.1 / 4.8 下，同一 canonical quad 的完整 PNG 与互补 pass 均为 RGBA 逐值 0 差
- 保留独立标准 Sprite 对照：原始 Sprite 与统一 quad 的透明 RGBA 最大差仍为 8，alpha 支持范围一致；合成到不透明灰底和实际地图后最大差均为 1 LSB。不能将此结果表述为“与原始 Sprite 全部逐像素一致”
- 原坐标补底：所有权内 7,685 个像素发生变化；遮罩外变化 0。保护三处高置信庭院核心，不声称模糊院墙边沿完整逐像素不变
- 实际现有学生，五表面前后可见像素：北 34→1,032、西 88→446、东 0→758、中央 353→1,055、南 0→1,252；隔离西翼 358→1,040
- 真实桌面手工：Up 走路、点击屋顶打开“文理楼”、Esc 关闭、Down 返回、返回校园入口、再次进入昌平均通过
- 原生预览为实际物理路径移动及正式拾取函数驱动的自动录制；它与手工记录分开标识。末段隐藏楼体时标注推定补底

CI 的通用 native runner 自动发现新增 `test_buct_changping_wenli.gd`；新增命名 GPU 步骤用 xvfb 运行同一 `capture_buct_changping_wenli.gd`，保存图像和机器报告供复核。

最终串行 headless 回归：文理楼 1,032、一教 942、图书馆 1,062、东路 41、柳湖 59、南桥 50，共 3,186 项、0 失败，全部退出 0。最小校园 stage 的 Linux PCK 导出退出 0，实际加载打包后的场景、PNG 与 `.bin` 资源探针通过。预览为 1280 × 720、20 fps、223 帧、11.15 秒；22 个轨迹采样均在已有可行走区。详细计数见 `BUCT_CHANGPING_WENLI_VALIDATION.json`。
