# 设置、桌面编辑与第四章 CC98 接线设计

## 目标

把手机里的“设置”从一次性弹窗改成可进入的像素风系统应用，并让它同时承担三件事：管理真实存在的客户端选项、管理桌面排列、承接第四章后台活动取证。CC98 的“学习天地”帖子在第四章提供自习路线资料，随后由玩家导入麦斯威夜间自习群继续核验。

## 已确认范围

- 手机逻辑画布保持 `430 × 860`，由 `PhoneShell` 继续负责缩放和居中。
- 设置页使用项目现有的黑色像素描边、低饱和纸白底、方形图标和有限色阶，不复刻参考图中的圆角玻璃视觉。
- 桌面长按 `450ms` 进入编辑模式。鼠标、触控和键盘均可移动应用位置。
- 微信、照片、CC98、浙大钉、设置、控制中心、时钟、记录恢复和语音备忘录属于剧情应用，只能移动。
- 求是潮骑行属于可选应用，可以删除。浙大体艺在相关章节完成前不可删除，完成后进入可选应用范围。
- 锁定中的剧情应用保留原图标、原名称和原网格位置，解锁前不可移动、不可删除。
- 被删除的可选应用可以在“应用管理”中恢复。
- 设置主玩法放在“电池与后台活动”中。第四章里玩家检查 `07:55` 附近的异常记录，选中相互矛盾的时间项，再执行校验并获得控制器认可的线索。
- “桌面与壁纸”提供一条可选玩法。玩家参照旧桌面截图恢复指定排布，完成后记录一条辅助线索，不阻断主线。
- CC98 “学习天地”在第四章出现一条资料索引帖。玩家从课程年份、自习教室与时间回复中选出可用材料，将路线摘要导入麦斯威夜间自习群，再回二楼核验。
- CC98 普通帖子继续承担校园环境信息，不泄露后续谜底。

## 页面结构

设置首页包含搜索框与八个可进入的分组。

1. 校园网络与移动数据
2. 声音与振动
3. 显示与辅助
4. 桌面与壁纸
5. 应用管理
6. 隐私与权限
7. 电池与后台活动
8. 系统诊断与关于

每个分组必须打开真实子页。已有能力直接调用当前状态和现有控制器。暂时没有全局行为的项目显示可核验的只读信息，不提供无效开关。

## 桌面交互

- 长按图标后，桌面进入编辑状态，图标在两个细微偏转帧之间轮换。
- 拖动经过其他可移动应用时交换位置，放开后写入存档。
- 可删除应用显示黑色圆点减号，点击后需要一次行内确认。
- 键盘用户先聚焦图标，长按 Enter 或 Space 进入编辑，再用方向键换位；Delete 只对当前可删除应用生效。
- 编辑状态提供“完成”按钮和退出提示，离开桌面时自动结束编辑状态。

## 第四章后台活动玩法

后台记录分成来源、时间、活动类型和耗电四列。玩家需要在一组正常记录中找到 `07:55` 附近的三条冲突记录。选择错误时保留当前页面并给出下一步提示；选择完整后才开放“核验系统时间”。成功写入第四章线索，后续时钟校准和自习路线可以读取该线索。

## CC98 与微信接线

- 学习天地帖子在第四章 A2 路线调查开始时进入剧情帖子列表。
- 玩家打开帖子并保存三个信息点。帖子内提供“导入麦斯威夜间自习群”按钮。
- 导入成功写入独立线索，微信页面随后展示一条带来源的群内摘要。
- 微信里的现场学生消息继续负责当前方向和时间，CC98 资料只提供旧记录与教室索引。
- 已经越过该阶段的旧存档自动补齐导入线索，避免退回已经完成的流程。

## 存档与迁移

- 桌面顺序和隐藏的可选应用写入 `UiState`。
- 读取旧存档时过滤未知应用 ID、去重、追加新应用，并保留锁定槽位。
- 第四章取证使用 `chapter4.clueIds`，不新增第二套章节状态。
- 编辑态、拖拽对象、当前设置子页和待确认删除属于临时 UI，不写入存档。

## 验收标准

- `430 × 860` 与 `390 × 844` 下设置页、子页和桌面编辑均无溢出。
- 鼠标、触控 Pointer Events、Enter、Space、方向键和 Delete 均有可见结果。
- 核心应用无法删除，可选应用能删除并从应用管理恢复。
- 刷新后桌面顺序和隐藏状态保持，旧存档可进入。
- 第四章 CC98 导入、微信显示、A2 核验形成一条完整链路，重复操作有明确反馈。
- CC98 新文案通过 human-writing 修订检查。
- `npm run typecheck`、第四章拓扑校验和定向空白检查通过。
- 本轮开发不运行 `npm run build:single`，也不改 `demo/index.html`。
