# 第四章母图空气墙、遮挡与物品识图提示词

## 坐标约定

- 本文覆盖 artifacts/chapter4-map-assets-20260820/base 下的 5 张母图。
- 坐标原点为图片左上角，X 向右，Y 向下，单位为源图像素。
- 本文坐标表中的 rect 统一写为 [x, y, width, height]；polygon 统一写为 [[x1,y1], [x2,y2], ...]；anchor 为 [x,y]。
- 逐图识图提示词要求模型输出 JSON 对象；其中每个矩形必须写成 {x,y,width,height}，避免数组字段顺序产生歧义。本文坐标表与模型输出格式有意区分。
- 全部坐标均为目测估算：approximate=true。接入运行时前必须重新按源图像素校准。
- 遮挡统一依据玩家脚点 actorFootY：玩家脚点位于对象基线 footY 以上且横向范围重叠时，对象前景层覆盖玩家；越过基线后玩家绘制在对象前方。
- 壁画、黑板、投影幕和壁灯随墙体处理，通常不建立额外实体碰撞。
- 楼梯需拆分为两侧栏杆空气墙与底部换层触发区；电梯门关闭时为实墙，交互后由控制器决定是否开放。
