# 食堂 755 米自行车追逐 · 美术重设计(暖色晨光)

日期:2026-08-06
分支:codex/bike-rush-visual-redesign
状态:已实现(构建与截图走查通过)

## 背景

追逐画面由 `ChaseRenderer.ts` 在 960×540 Canvas 上程序化绘制(`ChaseSprites.ts` 为孤立文件,不接回)。上一轮 redesign(6cad93d)确立了像素感程序化路线,本轮在其上全面精修,不改玩法与碰撞逻辑。

## 方向

- 路线:精修程序化绘制(不接回烘焙精灵)
- 影调:**暖色晨光**——清晨低角度阳光,金色受光面 + 长影子
- 优化范围:骑手与纸条主体、障碍可读性、环境与速度感、HUD 与反馈

## 设计要点

### 1. 影调
- 天空:顶部淡蓝 → 地平线蜜桃金渐变,低角度朝阳 + 光晕,慢速漂移的云
- 路面:暖褐灰沥青;草地/树木提高饱和度,带金色受光面
- 树、路灯、建筑投长影子(随距离滚动,兼作速度感)
- 远景建筑:暖砖/米白

### 2. 骑手与纸条
- 骑手:更清晰的共享单车(车架、挡泥板、车筐、轮圈转动暗示);人物加背包、衣角/头发飘动、更顺滑的 4 帧踩踏;换道倾斜带回弹
- 纸条:更大的翻滚动画 + 青色微光拖尾粒子 + 偶尔侧移;过里程碑时明显变大变近
- 速度:轮下尘土/落叶粒子;边缘速度线随 pace 加密

### 3. 障碍可读性
- 每个障碍底部加贴合车道透视的软阴影(读车道归属)
- 路障:A 字腿 + 警示灯闪烁;锥桶成组 + 反光条;汽车补车顶/车窗/车轮/刹车灯;停放自行车加车筐支架;人群姿态差异化;跨道跑者加奔跑动感
- 不改碰撞判定与生成逻辑

### 4. HUD(rpg.css + CanteenChaseOverlay 结构微调)
- 进度条:纸条 → 剧院主题,里程碑刻度保留
- 机会:图标式表达,aria 标签不变
- 里程碑 toast:暖金徽章;碰撞时机会卡震动/变灰
- 移动端按钮加大、暖色半透明

## 技术约束

- 只动视觉层:`ChaseRenderer.ts`、`rpg.css`、`CanteenChaseOverlay.tsx`
- 静态层仍烘焙进 background 离屏 canvas;动态元素保持廉价 rect,目标 60fps
- `reduceMotion` 行为全部保留;`ChaseRenderState` 接口不变
- 不删 `ChaseSprites.ts`(避免无关 diff);不碰工作区启真湖未提交文件
- 完成后 `npm run build:single` 验证
