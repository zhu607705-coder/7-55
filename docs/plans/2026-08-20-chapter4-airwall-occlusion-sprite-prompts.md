# 第四章透明精灵表：空气墙、触发区与遮挡提示词

## 1. 范围与坐标约定

本文档覆盖 `artifacts/chapter4-map-assets-20260820/sprites/` 中现有 6 张透明精灵表，只定义候选切片、锚点、物理碰撞、交互触发与遮挡关系。地图母图和时间态整图由另一份逐图识别结果负责。

- 源图坐标原点位于左上角。
- 矩形统一使用半开区间 `[x0,y0,x1,y1)`。
- `measuredAlphaBounds` 使用当前 PNG 在 Alpha 5% 阈值下得到的 `[x,y,width,height]`，属于当前文件的实测值，`measured=true`、`approximate=false`。
- `visualTrim`、`pivot`、碰撞盒、世界触发区和世界摆放点均来自目测与玩法推导，统一 `approximate=true`，接入前必须在实际地图中复核。
- 6 张图片均具有真实 Alpha 通道。
- 禁止执行 `alpha-to-collision`。半透明阴影、辉光、玻璃反射、指示灯、残影、时间粒子和零散亮点全部不得生成空气墙。
- 推荐公共深度带：`floor=0`、`floor_decal=10`、`wall_fixture=200`、玩家与落地物体 `1000+worldFootY`、前景墙帽和门楣 `8000`、UI `9000`。

最终 manifest 中的矩形不得保存为数组。本文表格继续使用便于核对的半开边界 `[x0,y0,x1,y1)`；输出 manifest 时统一转换为对象式 `{x,y,width,height}`，其中 `width=x1-x0`、`height=y1-y0`，并同时保留：

```json
{
  "sourceCell": { "x": 0, "y": 0, "width": 0, "height": 0 },
  "sourceTrim": { "x": 0, "y": 0, "width": 0, "height": 0 },
  "measuredAlphaBounds": { "x": 0, "y": 0, "width": 0, "height": 0 },
  "pivot": { "x": 0, "y": 0 },
  "collisionBounds": [],
  "interactionBounds": [],
  "approximate": true
}
```

没有规则 cell 的家具与残影使用 `sourceCell: null`；空白单元使用 `sourceTrim: null`。一个对象存在多个碰撞形状时，`collisionBounds` 保存对象式矩形或多边形数组。
