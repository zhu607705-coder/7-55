- 生成母图：`全局一致性锁定提示词 + 对应楼层母图提示词 + 对应楼层一致性附加段 + 全局负面提示词`。
- 生成时间态：把已确认母图作为参考图，使用 `全局一致性锁定提示词 + 对应时间态提示词 + 对应楼层一致性附加段 + 全局负面提示词`。
- 生成透明覆盖层：明确写入“透明背景、尺寸 1672×941、未修改区域 alpha=0、与母图逐像素对齐”。
