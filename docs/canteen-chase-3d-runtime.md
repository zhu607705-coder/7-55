# 755 米自行车追逐：本地 3D 运行规格

## 1. 目标

食堂扫码完成后直接进入一段固定 `755m` 的三车道自行车追逐，终点为求是大讲堂剧场入口。玩家、摄像机和终点楼均位于同一组三维世界坐标中，画面必须明确呈现道路从车轮下通过、沿街物体被玩家超越、剧场持续接近。

本规格只替换追逐的视觉渲染。距离、三车道选择、障碍生成、碰撞、机会次数、剧情完成、音频事件、DEV 检查点和存档继续由现有 TypeScript 控制器负责。

## 2. 本地素材与建模来源

- 场景色板沿用 `src/assets/rpg/canteen_chase/` 已有像素图中的蓝、黄、暖砖、米白、青色玻璃和低饱和草地。
- 障碍类型沿用 `ChaseGeometry.ts`：施工挡板、单车、路人群、路锥、车辆和横穿学生。
- 骑手外形沿用本地后视骑行立绘：蓝色外套、深色裤装、黄色车架、青色反光条。
- 终点楼以 `zijingang_campus_loop_panorama.png` 中实际剧场入口为视觉依据：白色椭圆屋顶、弧形蓝玻璃幕墙、白色立柱、中央双门、宽台阶、花坛和黑色校园路灯。
- 路线必须包含可读的紫金港身份锚点：`紫金港校区` 石牌、`求是路` 蓝色导视、校园自行车停放点、规整树阵、黑色校园路灯和 `求是大讲堂` 方向牌。
- 道路两侧按草坪树阵、校园楼群、启真湖水岸与湖畔玻璃楼轮换；同类模型不得连续铺满整段 755 米路线。
- 求是大讲堂保持低面数像素 3D 建模，不使用食堂立面、通用终点盒体或单张平面贴图替代。
- 运行时不请求 CDN、远程模型或远程纹理；Three.js 使用仓库依赖并进入离线单文件。

## 3. 坐标和镜头合同

- 画布逻辑尺寸固定为 `960×540`，保持 `16:9`。
- 里程映射固定为 `1m = 0.22` 世界单位。
- 玩家世界位置：`z = -distance × 0.22`。
- 三条车道中心：`x = -3.35 / 0 / 3.35`。
- 终点楼固定在 `755m` 之后约 `8` 个世界单位，禁止通过屏幕缩放伪造接近。
- 摄像机位于玩家后方并跟随玩家世界坐标；换道时保留横向跟随迟滞，骑行时保留小幅硬边镜头起伏。
- 摄像机保持能看清车把、前叉、前轮和双手的近距离后视构图；换道时产生轻微侧向跟拍，但不得把骑手裁出画面。
- 道路、路灯、树、楼房、路人和障碍物拥有固定或规则更新的世界坐标。禁止把整张背景向后滚动作为主运动来源。

## 4. 骑手模型与动画

- 骑手、车架、前叉、车把、前后轮、四肢分层建模。
- 前叉、前轮和车把属于同一个 `frontAssembly`。
- 向左换道时，前轮的世界前向必须指向负 `x`；向右换道时指向正 `x`。
- 车身侧倾和车把转角读取同一换道速度。屏幕后视构图下，车身向换道侧倾，前轮和车把朝实际目标车道偏转；两者分别计算显示符号，防止后视投影把龙头方向画反。
- 前后轮按实际前进距离旋转；双腿按统一相位交替踩踏。
- 任何动画帧不得修改模型整体尺寸，防止周期性抽搐。

## 5. 路人与障碍

- 路人只出现在人行道，模型朝向必须与其世界位移方向一致。
- 同向路人与逆向路人均可存在；腿部摆动方向、模型朝向和世界位移必须一致。
- 玩家超越路人产生向后离开视野的相对运动，这是摄像机前进结果，路人世界坐标仍按自身方向移动。
- 正式碰撞继续使用 `ChaseGeometry.ts` 的车道与里程数据，Three.js 模型不得建立第二套判定。
- 横穿学生根据其障碍阶段从人行道走向目标车道，模型朝向同步更新。

## 6. 像素 3D 画风

- `antialias: false`，像素比固定 `1`，禁止写实抗锯齿。
- 使用低面数几何、离散色板、`flatShading` 和硬边块状阴影。
- 禁止照片材质、软阴影、景深模糊、运动模糊和高光金属表面。
- 树冠使用低阶多面体；人物、建筑、车体以体素盒体为主。
- 雾只负责远景层次，不得遮挡临近障碍和纸条。

## 7. 兼容与回退

- WebGL 能力通过实际上下文探测决定，禁止通过 UA 判断。
- WebGL 可用时启用 `ChaseThreeRenderer`。
- WebGL 不可用时保留原 `ChaseCanvasRenderer`，剧情和控制器照常运行。
- React StrictMode 卸载时释放几何、材质和渲染器，但不主动使复用中的画布上下文失效。
- 桌面键盘和移动端触控继续使用 `CanteenChaseOverlay` 现有输入入口。

## 8. 验收标准

1. 从 `0m` 到 `755m`，终点楼的屏幕占比持续增加。
2. 道路标线、树、路灯和两侧楼房从远处进入并从玩家身后离开。
3. 左右换道时车把、前轮和车身侧倾方向一致，停止换道后平滑回正。
4. 骑手整体尺寸固定，踩踏循环中不得发生缩放抽搐。
5. 路人朝向与自身行走方向一致。
6. 三车道碰撞、三次机会、失败重试与 `755m` 完成条件保持现有结果。
7. Blink、Gecko、WebKit 的桌面和移动视口无页面错误、无文档溢出。
8. `npm run typecheck` 与 `npm run build:single` 通过，生成单文件不依赖网络资源。
9. 开局可见紫金港石牌，中段可见求是路或剧场导视，后段可辨识求是大讲堂的圆形屋顶、玻璃幕墙和入口标牌；这些地标随真实世界距离进入和离开相机。
10. 沿途至少出现两段可辨识水岸，水面、岸线和湖畔楼保持固定世界坐标，并与草坪和楼群路段连续交替。
