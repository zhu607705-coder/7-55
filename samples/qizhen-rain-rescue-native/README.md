# 7:55 · 启真湖雨天救援 · 独立 Godot 演出样例

## 打开

用 Godot **4.6.3** 打开 `project.godot`，运行主场景。工程自带所需纹理和字体，可离线运行。

- 15 秒演出：雨中失衡 → 落水并保持头部露出 → 抛圈拉回 → 老师拉扶、安全员接圈 → 上岸披毛巾 → 湿衣滴水与脚印
- 空格/P：暂停与继续
- R：重播
- Esc：直接看安全上岸状态
- 演出结束后 WASD/方向键：在码头木板上走动，检查持续湿衣与脚印
- M：减少雨线、水花与湿衣滴水数量
- 竖屏有额外的大号暂停、重播和跳过按钮

这是**独立视觉验证工程**。没有写入游戏存档，没有跳转宿舍，没有接入正式 `c3_rain_rescue_result`，没有变更 PR #144 或楼梯代码。该剧情位于黑天鹅追逐之前。

## 实现

不是视频播放器。雨湖底图、船壳、学生、老师、安全员、救生圈、绳、前景水线、水花、毛巾、滴水和脚印是独立 Godot 绘制层，由同一个确定性时间轴取样。

- 雨天底图沿用游戏原素材，不重新生成湖岸或码头
- 独立船壳从原可编辑 SVG 拆分，翻船后使用独立船底层
- 两套透明人物姿态图集及一张专用安全员接圈姿态由 OpenAI 内置 image_gen 生成；图集保留原图，不裁改角色像素，运行时采样已量好的区域
- 姿态采样、镜像和接触点见 `scripts/rain_rescue_preview.gd`
- 主演出模型见 `scripts/rescue_timeline.gd`
- 水面底图自带静态雨纹，本工程额外绘制动态雨线、水花和接触波纹；不含另一个独立水面 shader 样例

## 预览说明

随附 MP4 是 **Godot Movie Maker 的固定 30 fps 离线录制**，用于审看原生演出，不是实时帧率测量。工程本身实时绘制，暂停和重播无需加载视频。样例暂时无配音和音效。
